### The Tasteful Agent: Measuring and Improving Taste in Long-Horizon Tasks
**118 upvotes** · Wenbo Pan, Zhichao Liu, Shujie Liu et al. (Microsoft Research) · [Paper](https://huggingface.co/papers/2609.25804)

Long-horizon agents (coding, research) constantly face decision forks that silently determine whether a run will succeed or fail — a capability the authors call **"taste"**. They introduce **Taste-Bench**, automatically mined from parallel agent trajectories, where models must pick the better direction at a fork without seeing future steps. Frontier models top out at only 59.7% accuracy, and a larger reasoning budget doesn't help. Crucially, taste can be *trained*: distilling outcome-aware teacher judgments into a student model improves end-to-end performance on held-out SWE-bench Pro tasks, suggesting a practical path to better agents.

### RULER: Instance-aware Rubric Rewards for SVG Generation
**64 upvotes** · Hangyu Ran, Yuhao Zheng et al. · [Paper](https://huggingface.co/papers/2609.25270)

Generating SVG from text is hard to evaluate because there is no pixel-level ground truth, and scalar metrics like CLIP score are calibrated for natural images — reusing them as RL rewards leads to reward hacking. RULER converts each text prompt into an instance-specific 6-axis rubric (semantic, visual, stylistic) scored by a VLM judge, then trains via Group Relative Policy Optimization. On MMSVG-Illustration/Icon benchmarks, rubric score jumps from 0.432/0.395 to 0.693/0.683, beating dedicated SVG specialists and matching the much larger DeepSeek-V3, without needing paired SVG data or human labels.

### GAE: Learning a Geometry-Native Latent Space for 3D-Consistent World Generation
**42 upvotes** · Jiahao Lu, Minghao Yin, Wenbo Hu et al. · [Paper](https://huggingface.co/papers/2609.24981)

Standard video generators encode appearance-centric latents that don't preserve 3D structure, causing temporal incoherence in world-generation tasks. The **Geometry-native AutoEncoder (GAE)** reparameterizes a geometry foundation model's feature space into a compact latent jointly decodable to appearance, depth, cameras, and point maps. Swapping in GAE as the latent space for a standard conditional flow model cuts FVD by 12.7–23.1% on RealEstate10K and DL3DV, and halves camera-trajectory error — all without touching the generator or training protocol, suggesting the latent space itself is the bottleneck for 3D coherence.

## 🛠 Tools

### vectorize-io/hindsight — Agent Memory That Learns
**1,607 stars/day** · 26,963 total stars · Python · [Repo](https://github.com/vectorize-io/hindsight)

Hindsight is an open-source (MIT) agent memory system designed to make agents **learn** from past runs, not just recall conversation history. Unlike retrieval-augmented memory stores, it distills behavioral patterns across sessions so agents improve their decisions over time. It has a companion paper (arXiv 2512.12818), a cloud offering, and integrations across major frameworks — the 1,600+ stars/day spike suggests it's trending heavily today.

---

### google/ax — Google's Open Agentic Orchestration Runtime
**1,376 stars/day** · 9,709 total stars · Go · [Repo](https://github.com/google/ax)

AX is a declarative, Kubernetes-flavored orchestrator for running agent workloads at scale — think `kubectl apply` but for autonomous tasks with sandboxed execution, network fencing, and MCP server wiring. It targets multi-billion task clusters and is built on top of the Agent Substrate sandbox runtime. Still pre-stable with breaking changes expected, but the YAML-based task/workspace/gateway primitives already offer a compelling model for production agent infrastructure.

---

### obra/superpowers — Agentic Skills Framework for Coding Agents
**606 stars/day** · ~291,000 total stars · Shell · [Repo](https://github.com/obra/superpowers)

Superpowers is a methodology and composable skills layer that plugs into virtually every major coding agent (Claude Code, Cursor, Copilot CLI, Gemini CLI, Devin, Codex, and more). It enforces a spec-first, TDD, subagent-driven development loop — agents write a plan before touching code and use child agents to execute individual tasks. With nearly 291k total stars it's one of the most adopted agent workflow layers in the ecosystem, and it's still actively maintained.
