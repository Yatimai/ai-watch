### Tree-Ising: Repairing Language Models with Bit-Level Ising Edits
**58 upvotes** · Hadi Salloum, Ammar Ali · [Paper](https://huggingface.co/papers/2611.14210)

Tree-Ising reframes LLM weight repair as a sparse discrete optimization problem: rather than using an LLM agent to rewrite weights (158 turns, 89.7M tokens, ~expensive), it formulates the fix as a set of independent QUBO/Ising problems solved by GPU simulated annealing or quantum-inspired simulated bifurcation. On Qwen3.5-0.8B it beats the GPT-6 Astra agent edit on MATH-500 (55.1% vs 51.7%), flips 2.2–2.3× fewer bits, and costs roughly $0.90 in GPU time with zero LLM tokens. On Qwen3.5-2B, the same recipe jumps greedy GSM8K accuracy from 21.6% to 69.4% with only 4 forward passes — a compelling signal that gradient-free, combinatorial weight surgery is a viable and cheap alternative to agent-based model repair.

### World In-Context Learning for Agentic Robot Manipulation
**52 upvotes** · Heng Fang et al. · [Paper](https://huggingface.co/papers/2611.12885)

WICL (World In-Context Learning) lets a frozen robot policy learn a manipulation task from a single demonstration by rehearsing it in simulation and writing feedback into its *context* rather than its weights — no gradient updates required. The RoboScript infrastructure implements this for 50 RoboTwin 2.0 tasks, achieving 83.4% mean success rate with one demo per task, outperforming the best trained policy by over 20 points. The key insight — that in-context learning captures semantics (task steps, object roles) rather than visual appearance — is what enables cross-scene and cross-embodiment transfer. Code is open at [github.com/ArcheOne-AI/RoboScript](https://github.com/ArcheOne-AI/RoboScript).

### Don't Just Trust Your Memory: Evidence-Linked Memory Reduces Memory-Induced Degradation in LLM Agents
**46 upvotes** · Yukyeong Lee et al. · [Paper](https://huggingface.co/papers/2611.14320)

LLM agents that learn from memory can regress on tasks they would solve without it — "memory-induced degradation" — because distilled lessons carry no provenance. WikiTrace fixes this by storing each lesson alongside a trajectory summary and the raw trajectory itself; at inference, the agent can descend through these links to verify, fill in, or correct a lesson before acting. Evaluated across five agentic benchmarks, WikiTrace consistently outperforms existing memory approaches while reducing degradation. It's a lightweight but principled addition to any retrieval-augmented agent loop — code at [github.com/yukyeongleee/wikitrace](https://github.com/yukyeongleee/wikitrace).
