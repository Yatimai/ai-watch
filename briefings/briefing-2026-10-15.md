## 🔬 Research

### Player-1: Learning to Play from Synthetic Experience
**126 upvotes** · Mingyu Ouyang et al. · [Paper](https://huggingface.co/papers/2610.20584)

Player-1 is a post-training framework that teaches game-playing agents through synthetic experience rather than relying solely on human demonstrations. The team built Player-1-Gym, 16 synthetic 2D/3D environments, and used PPO reinforcement learning on top of supervised fine-tuning — resulting in Player-1-9B reaching 38.33% success on MineDojo-300 vs. 12.63% for the strongest baseline (+27.8 pp over its own SFT policy). The key insight is that broader synthetic environment coverage improves cross-game transfer, and RL naturally discovers composite keyboard+mouse actions that SFT alone never learns. This matters because it establishes a scalable path toward general-purpose computer-use agents that can learn game control without needing large human-labeled datasets.

### Doc2Harness: Benchmarking LLMs on Long-Horizon Harness Engineering of Coding Agents
**78 upvotes** · Yuyao Ge et al. · [Paper](https://huggingface.co/papers/2610.20344)

Doc2Harness benchmarks something most evaluations ignore: the ability of LLMs to *build* the harness wrapping a coding agent, not just use one. A model reads an interface contract and documentation, constructs a full candidate harness in an isolated container, and is then scored across 328 test cases using 4 observable channels (model requests, disk files, exit codes, stdout). Across 19 frontier models, GPT-6 Astra leads at only 53.05% pass rate — meaning even the best model fails nearly half the cases — with failures clustering around cross-module responsibility splitting. For AI engineers building agentic pipelines, this benchmark directly measures real-world scaffolding skill rather than downstream task proxies.

### RuleTrek: Benchmarking Agentic Rule Reasoning in Complex Scenarios
**54 upvotes** · Chenhao Yuan et al. · [Paper](https://huggingface.co/papers/2610.19698)

RuleTrek is a multi-domain benchmark targeting a specific LLM weakness: applying domain-specific rules when relevant information is scattered across multiple files in an interactive workspace. It tests three distinct capabilities — Rule Identification, Rule Deduction, and End-to-End Reasoning — and finds that even the best frontier models top out at 62.47% on RI and 60.43% on RD, with E2E scores ranging from 27% to 55%. Existing benchmarks typically spoon-feed rules in a few statements; RuleTrek's realistic multi-file setups reveal a meaningful capability gap for agents deployed in legal, medical, or compliance settings. Code and dataset are [publicly available](https://github.com/yuan247/RuleTrek).

## 🛠 Tools

### morluto/rea — Reverse-engineer anything, from apps to native binaries
**32,282 stars/day** · [Repo](https://github.com/morluto/rea)

REA is a TypeScript MCP (Model Context Protocol) server that exposes a unified reverse-engineering interface to any AI agent, letting it analyze runtime behavior, decompile binaries, and inspect applications through a single tool. With 258K total stars and active pushes today, it is clearly the viral tooling story of the week — likely amplified by the broader AI decompilation conversation (see SW-8 below). Licensed MIT, it plugs into Claude, Cursor, and any MCP-compatible host, making binary-level analysis a one-liner for coding agents.

### debpalash/VoiceStudio — Fully-local, open-source ElevenLabs alternative
**3,027 stars/day** · [Repo](https://github.com/debpalash/VoiceStudio)

VoiceStudio is an Electron + Python app that runs voice cloning, voice design, video dubbing, dictation, transcription, and audiobook generation entirely on-device across 646 languages, defaulting to the OmniVoice model from k2-fsa. It ships a local API and MCP server for agent integration, plus automation features like watch folders and reusable recipes. Licensed AGPL-3.0 with 67K total stars, it is a serious privacy-first alternative to cloud TTS/dubbing services — relevant for any team that can't send audio data to third-party APIs.

### AI is mass decompiling games. That's both awesome and scary.
*2026-10-14* · [Post](https://simonwillison.net/2026/Oct/14/ai-is-mass-decompiling-games/) · tags: `ai-ethics`, `coding-agents`, `game-design`, `webassembly`

Simon links to an indie developer's essay on the current AI decompilation wave, which is enabling game mashups, cross-platform ports (often to WebAssembly/browser), and a preservation boom for games rendered unplayable by server shutdowns. The flip side is existential for software IP: any app, not just old games, can now be reverse-engineered and redistributed against its owners' wishes. The timing alongside `morluto/rea` going viral with 32K stars/day is not a coincidence — the tooling and the cultural debate are arriving together.

### Redesigning source control at Anthropic
*2026-10-13* · [Post](https://simonwillison.net/2026/Oct/13/redesigning-source-control-at-anthropic/) · tags: `git`, `version-control`, `anthropic`, `agentic-engineering`

Anthropic published an engineering post explaining why they replaced Git with an in-house system called **Scion** (code review: **Antique**): AI-assisted coding drove commits from ~2,500/day in May 2026 to over 30,000/day by September — a 12× increase in six months. The scale makes Git impractical: the main branch history alone is ~100 GB, and 25 million daily CI checkouts would naively generate 600 PB of Git traffic. Simon flags that Scion resembles centralized VCS (à la Subversion/Google Piper/Meta Sapling) and notes that Claude is "by far the heaviest user" — offline support was deprioritized accordingly. This is a leading indicator of the infrastructure changes that come when AI agents become the dominant committers in a large codebase.

### Tree Appreciator — Vibe-coding a game in 3 hours with Claude Opus 5.5
*2026-10-14* · [Post](https://simonwillison.net/2026/Oct/14/tree-appreciator/) · tags: `vibe-coding`, `claude`, `three-js`, `game-design`

Simon built a playable Three.js spot-the-difference game with procedurally generated trees purely by prompting Claude Opus 5.5 Max on his iPhone — no code editor, no Claude Code mode. The practical takeaway: telling Opus 5.5 to "make sure it is fun" is now a surprisingly effective design directive, and the gap between a prompt and a shippable creative artifact continues to shrink.
