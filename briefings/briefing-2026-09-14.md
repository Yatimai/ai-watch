## 🔬 Research

### Scaling Automatic Research Agents via World Models
**452 upvotes** · Yang et al. (Xiyuan Yang, Sheikh Sarwar, Jingru Cheng et al.) · [Paper](https://huggingface.co/papers/2608.12564)

AutoResearch agents trained with RL hit a hard wall: while inference batches cheaply on GPUs, each environment execution (running code in a sandbox) hogs a dedicated machine for real time — making it the dominant training bottleneck as trajectories grow. WMRL replaces live environment execution with a learned world model, cutting training time by **3–4×** while boosting performance. The kicker: their post-trained **4B and 9B agents outperform open-weight models of 48B and 120B** on held-out benchmarks, and the approach also transfers to embodied VLA policies.

### NCP-ArchPreview: Moving Towards Latent Space Language Models via Next Concept Prediction
**303 upvotes** · NCP Team (Jiaqi Cao, Chiyu Chen, Shuang Cheng et al.) · [Paper](https://huggingface.co/papers/2609.10715)

Instead of predicting only the next token, NCP-ArchPreview jointly predicts discrete multi-token *concepts* drawn from a product-quantized latent vocabulary built from the model's own hidden states. Scaled to **8.9B parameters on 5.73T tokens**, it matches OLMo-3-7B's final training loss using only **51.3% of the training tokens**, and outperforms it by 2.45 points on downstream tasks (+5.99 on GSM8K). Beyond pretraining, the 17M-parameter VQ module alone provides a lightweight domain-adaptation interface, and injecting concept representations into a speculative drafter improves accepted token length by 4.17%.

### SenseNova-U1.5: Native Unified Visual Intelligence
**248 upvotes** · Diao et al. (SenseTime) · [Paper](https://huggingface.co/papers/2609.11929)

SenseNova-U1.5 is an **8B Mixture-of-Tokens** multimodal model that handles image understanding, reasoning, generation, and editing within a single encoder-free, VAE-free architecture — a meaningful architectural simplification over most unified models. It supports native resolutions up to **4K** and handles bilingual text rendering, infographics, and multi-reference editing, with specialized experts consolidated via on-policy distillation. Despite seeing few structured formats during training, it generalizes to complex structured visual instructions, suggesting that understanding capabilities genuinely transfer to visual planning. Training code (SFT, RL, distillation) will be open-sourced.

## 🛠 Tools

### debpalash/VoiceStudio — Fully local ElevenLabs alternative
**2,632 stars/day** · 28,353 total stars · [Repo](https://github.com/debpalash/VoiceStudio)

A local, zero-subscription voice toolkit covering voice cloning, video dubbing, dictation, transcription, and audiobook creation across **646 languages**, running on macOS, Windows, Linux, and Docker. It bundles **16 TTS engines and 11 ASR engines**, requires no account or API key, and an Electron desktop rewrite is currently in progress. For teams looking to eliminate dependence on ElevenLabs or similar APIs for production pipelines, this is the most feature-complete self-hosted option available.

### JustVugg/colibri — Run 744B–2.8T MoE models on consumer hardware
**868 stars/day** · 31,205 total stars · [Repo](https://github.com/JustVugg/colibri)

Colibri is a pure-C, zero-dependency inference engine that streams MoE experts from disk, treating VRAM, RAM, and storage as a single unified memory hierarchy — making frontier-scale models like **Kimi K3 (2.8T)**, **DeepSeek V4.1 Flash (552B)**, and **GLM-5.2 (744B)** runnable on hardware you already own. Nine model families are supported today, each implemented as a single C file with a unified `coli chat / serve / web` frontend. It's deliberately an aggressive research platform (no speed SLA, hard semantic guarantees), actively pushed as of today.

### TauricResearch/TradingAgents — Multi-agent LLM financial trading framework
**756 stars/day** · [Repo](https://github.com/TauricResearch/TradingAgents)

### commit-rewriter 0.1
*2026-09-14* · [Post](https://simonwillison.net/2026/Sep/14/commit-rewriter/) · tags: `git`, `projects`, `python`, `ai-assisted-programming`

Simon built a small Python web app (`uvx commit-rewriter path/to/repo`) to clean up AI-agent-generated commit messages — removing coding-agent cruft and private issue references before making a repo public, as he needed to do for Datasette security releases. On submit, it creates a timestamped safety branch then rewrites all affected commits. A practical, low-ceremony tool that addresses a real friction point in AI-assisted development workflows.

### Generating Running Routes with GPT-6 Astra and ChatGPT Work
*2026-09-12* · [Post](https://simonwillison.net/2026/Sep/12/astra-running-routes/) · tags: `geospatial`, `ai`, `d3`, `openai`, `gpt-6-astra`

Simon used ChatGPT Work (backed by GPT-6 Astra Max) to generate 5K and 10K running routes from his home address — the agent autonomously used Nominatim, Overpass/OSM data, and D3 to produce an embedded map visualization plus GPX/GeoJSON downloads, all in 27 minutes. He raises two pointed criticisms: the agent's intermediate code was invisible in the UI, and thread compaction destroyed the ability to retrieve the Python code after the fact. This is a useful real-world stress-test of agentic UX — the capability is impressive, but opacity and compaction remain unsolved design problems.
