### OpenART: Scaling Agent Red Teaming via Open-Ended Environment Evolution
**252 upvotes** · Yunhao Chen, Xin Wang, Yixu Wang et al. · [Paper](https://huggingface.co/papers/2608.00677)

Most safety benchmarks test LLMs on short, static tasks — but real-world agents operate in persistent, evolving environments where early state changes compound over long workflows. OpenART addresses this with 10,000+ validated stateful scenarios across 50 domains and a pool of 500,000+ tools, requiring a median of 97 tool calls per task. The proposed Evolutionary Markov Hypergraph Attack (EMHA) achieves an 85% Attack Success Rate across 75 agent-model configurations, with its advantage over simpler baselines growing from ~2% on simple tasks to over 17% on complex ones. A key finding: the runtime implementation of an agent accounts for significant safety variance beyond what the underlying model alone would predict.

### Alaya-EVOKE: From Linear-Scaling Supervision to Endless World
**112 upvotes** · Yuanyang Yin, Gongxuan Wang, Yifan Zhan et al. · [Paper](https://huggingface.co/papers/2608.13546)

Evoke is an interactive world model that tackles the fundamental tension between long-session memory, low-latency generation, and long-horizon consistency. It externalizes world state into a camera-indexed memory bank (keeping the denoiser context bounded regardless of session length), and uses a teacher model with sparse linear attention to provide supervision over long horizons — preventing content drift that slips through short windows. A 3-step student model, trained via distribution matching under self-forced rollouts, runs without classifier-free guidance and generates 1.5s video chunks in 2.11s on a single H200. Evoke achieves state-of-the-art on WBench while remaining competitive on VBench-Long and VBench-2.0.

### LLMRouter: Unified Infrastructure for Developing, Evaluating, and Deploying LLM Routers
**97 upvotes** · Tao Feng, Fangxu Yu, Haozhen Zhang et al. · [Paper](https://huggingface.co/papers/2608.06867)

No single LLM dominates all query types and cost constraints, making routing between models an increasingly practical concern. This paper proposes a unified 5-component formulation of LLM routing (context encoder, model encoder, scoring function, decision rules, learning signals) covering single-turn, multi-turn, and personalized scenarios. The accompanying benchmark **xRouteBench** spans generic, vision, time-series, and memory-augmented routing tasks; the open-source **LLMRouter** library packages 16+ routing strategies. Learned routers outperform the best fixed-model baseline by 14.6%, and lightweight routers hold up competitively under tight cost budgets.

### cactus-compute/needle — 14 MB foundation model for edge devices
**547 stars/day** · [Repo](https://github.com/cactus-compute/needle)

### Don't classify. Hallucinate!
*2026-08-14* · [Post](https://simonwillison.net/2026/Aug/14/dont-classify-hallucinate/) · tags: `search`, `llms`, `embeddings`

Doug Turnbull's technique inverts the standard classification approach: instead of asking an LLM to pick from a large existing tag vocabulary (which may be too big to fit in context), ask it to freely *invent* plausible tags, then use vector embeddings to snap those hallucinated tags to the closest real ones. This sidesteps the context-length bottleneck and tends to produce more semantically coherent matches than forcing a choice from a list. A simple but practical trick for any content tagging or search pipeline built on top of an existing taxonomy.
