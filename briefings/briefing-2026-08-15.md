### OpenART: Scaling Agent Red Teaming via Open-Ended Environment Evolution
**252 upvotes** · Yunhao Chen, Xin Wang, Yixu Wang, Yi Liu, Jie Li · [Paper](https://huggingface.co/papers/2608.00677)

Current safety benchmarks evaluate LLMs on short, static tasks — but AI agents operate in long-horizon, stateful environments where early actions compound over time. OpenART addresses this gap with 10,000+ validated scenarios across 50 domains, drawing from 500,000+ tools, with a median task requiring 97 tool calls. The proposed black-box attack policy, EMHA, achieves an 85% Attack Success Rate across 75 agent-model configurations, and its edge over simpler instruction-only attacks grows from ~2% on easy tasks to 17%+ on the hardest ones. A sobering finding: the specific runtime implementation of an agent explains safety variation independently of the underlying model's capabilities.

### Alaya-EVOKE: From Linear-Scaling Supervision to Endless World
**102 upvotes** · Yuanyang Yin, Gongxuan Wang, Yifan Zhan, Chuanhao Li, Kaipeng Zhang · [Paper](https://huggingface.co/papers/2608.13546)

Evoke is an interactive world model designed for open-ended, long-horizon video generation without the usual memory blowup. It externalizes scene geometry into a camera-indexed state bank and uses a linear-attention teacher for supervision over long sequences, keeping context bounded as sessions grow. A 3-step student model then transfers these capabilities with no classifier-free guidance, generating a 1.5-second chunk in 2.11s on a single H200. The result is state-of-the-art on WBench while remaining competitive on VBench-Long and VBench-2.0 — a meaningful step toward real-time, persistent virtual worlds.

### LLMRouter: Unified Infrastructure for Developing, Evaluating, and Deploying LLM Routers
**91 upvotes** · Tao Feng, Fangxu Yu, Haozhen Zhang, Zhongjie Dai, Liangqi Yuan · [Paper](https://huggingface.co/papers/2608.06867)

LLM routing — deciding which model to call per query to balance cost and quality — lacks standardized evaluation frameworks, making it hard to compare approaches. This paper formalizes routing as a 5-component sequential decision process and ships `LLMRouter`, an open-source library with 16+ router implementations, plus `xRouteBench`, a benchmark spanning generic, vision, time-series, and personalized routing tasks. Key empirical finding: learned routers beat the best fixed-model baseline by **14.6% relatively**, and lightweight routers become surprisingly competitive under tight cost budgets. Practically useful for any team running multiple models in production.

## 📡 Analysis

### Don't classify. Hallucinate!
2026-08-14 · [Post](https://simonwillison.net/2026/Aug/14/dont-classify-hallucinate/) · tags: `search`, `ai`, `generative-ai`, `llms`, `embeddings`, `doug-turnbull`

Doug Turnbull's technique for auto-tagging with LLMs: instead of feeding the model your full taxonomy (potentially thousands of tags), let it freely hallucinate plausible tags for the content, then use vector embeddings to find the closest real tags in your existing corpus. This sidesteps the context-window problem for large vocabularies and avoids forcing the model into rigid classification. Simon flags it as a useful trick for his own 1,856-tag blog archive — a pattern broadly applicable to any classification-at-scale problem.

### sqlite-utils 4.2.1
2026-08-13 · [Post](https://simonwillison.net/2026/Aug/13/sqlite-utils-2/) · tags: `packaging`, `python`, `sqlite-utils`, `uv`

Patch release fixing a crash introduced in 4.2 where `from typing_extensions import Self` was used but `typing-extensions` wasn't declared as a direct dependency — it only arrived transitively through dev deps, breaking `uvx sqlite-utils` for end users. The fix also surfaces a handy `uv` smoke-test pattern: `uv run --isolated --no-default-groups sqlite-utils --help` to verify the CLI works without dev dependencies. A useful reminder to always explicitly declare runtime deps even when they're reliably available in your local dev environment.
