## 🔬 Research

### Waypoint-OPD: Transferring RL-Induced Policy Shifts via Gated On-Policy Distillation
**181 upvotes** · Bingxi Hou et al. · [Paper](https://huggingface.co/papers/2610.21601)

Standard policy-shift distillation blindly transfers the net difference between a teacher model's pre- and post-RL log-probabilities, missing the fact that intermediate training dynamics can be contradictory. Waypoint-OPD adds a single intermediate checkpoint from the same RL run to detect directional agreement between early and late policy shifts, and gates the final distillation signal accordingly. Tested on Qwen3-4B teachers with Qwen3-8B/14B/30B students across math and code reasoning, it tops all six domain–student settings at the cost of just one extra frozen-teacher scoring pass. A practical, low-overhead improvement for anyone building smaller models from RL-trained teachers.

### Self-Evolving Agent Harness
**147 upvotes** · Chuyang Wei et al. · [Paper](https://huggingface.co/papers/2610.18813) · [Code](https://github.com/zgcagi/Harness-RSI)

This 66-page paper formalizes *harness self-evolution*: an agent that rewrites its own scaffolding (prompts, memory, workflows, plugins, executable code) while leaving model weights frozen. The framework provides PAC-learning-derived generalization and retention bounds, plus a high-probability admission rule to validate each revision on fresh data before it persists. The governance implications — around scientific reliability, physical safety, and institutional accountability — get explicit treatment, making this a useful reference for anyone deploying long-running agentic systems.

### RoTA-Bench: Evaluating 3D Spatial Reasoning through Interactive Projection Alignment
**142 upvotes** · Qingchuan Ma et al. · [Paper](https://huggingface.co/papers/2610.17665)

RoTA-Bench probes whether VLMs can mentally rotate 3D objects and recover a target silhouette through sequential rotation commands — a task requiring genuine geometric reasoning rather than pattern matching. The benchmark covers 674 tasks (100-task stratified test set); GPT-5.6-Sol succeeds on only 17%, while 20 undergrads achieve 100%. A notable finding: models disproportionately improve silhouette overlap while *worsening* true pose alignment (19.4% of states vs. 10.9% for humans), revealing a systematic gap between visual matching and real 3D control that current VLMs haven't closed.

### xerj-org/xerj — Token-efficient semantic search engine for AI agents
**1647 stars/day** · 6.4k total stars · [Repo](https://github.com/xerj-org/xerj)

XERJ is a Rust-based indexer and search engine (Apache-2.0) that auto-indexes code, docs, logs and PDFs and exposes BM25 + kNN hybrid search via an Elasticsearch-compatible API, plus a native MCP interface. The headline claim is 40× fewer tokens than `grep` for agent data retrieval (2.7× fewer for reference coding tasks). It's designed as a drop-in agent memory and RAG backend with zero-config autoindex — directly relevant for anyone building coding agents or document-heavy RAG pipelines.
