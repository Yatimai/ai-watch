### Apodex 1.1: Scaling Agentic Intelligence for Complex Work
**140 upvotes** · Apodex Team · [Paper](https://huggingface.co/papers/2608.23283)

Apodex 1.1 frames the core challenge as "working capability" — sustained, verifiable progress on real-world tasks requiring file manipulation, code execution, state maintenance, and failure recovery. It scales along two axes: environment diversity/verifiability, and multi-agent coordination (task decomposition, parallel delegation, async result integration, replanning). Despite being considerably smaller than many frontier systems, the 35B-parameter Apodex 1.1 reaches top-tier performance across finance, science, math, and coding benchmarks. The 35B Mini variant is locally deployable, which is notable for teams wanting agentic capability without cloud dependency.

### EchoWM: Open and Enterable Omnimodal World Models
**43 upvotes** · Songchun Zhang et al. · [Paper](https://huggingface.co/papers/2608.23189)

EchoWM is a world model that generates interactive, navigable media at 720p — simultaneously producing video, environmental sound, music, and speech — while responding to continuous 6-DoF camera or character control. It uses a unified metric-scale trajectory representation that works across first- and third-person perspectives and heterogeneous training data. The progressive + autoregressive post-training pipeline enables long-horizon generation with synchronized audio-visual coherence. This matters because it pushes toward playable, immersive generative environments rather than passive video synthesis.

### Graph Engineering in the Era of LLM Agents
**41 upvotes** · Yuyuan Feng et al. · [Paper](https://huggingface.co/papers/2608.21156)

The paper argues that as multi-agent systems grow more complex, prior paradigms (prompt, context, harness, loop engineering) all optimize at the individual agent level and hit an architectural ceiling. The proposed "Graph Engineering" paradigm instead builds explicit, dynamic graph structures representing tasks, agents, and execution states, enabling coordinated "System Intelligence" across heterogeneous specialist agents. It's a systematic survey of the design space, and a curated resource list is maintained at [github.com/DEEP-JLU/Awesome-Graph-Engineering](https://github.com/DEEP-JLU/Awesome-Graph-Engineering). Useful framing for anyone architecting production multi-agent pipelines.

### NousResearch/hermes-agent — Self-improving AI agent with a built-in learning loop
**896 stars/day** · [Repo](https://github.com/NousResearch/hermes-agent)

Hermes Agent (MIT license, 236k total stars) is NousResearch's open-source agent that builds a persistent skill library from past conversations, searches its own history, and progressively deepens its model of the user across sessions. It runs on any model backend (Nous Portal, OpenRouter, OpenAI, custom endpoints) and is designed to run cheaply on a $5 VPS or serverless infra — not tied to a local machine, accessible via Telegram. It's one of the more serious open implementations of a "growing" agent with durable memory, standing out from stateless chat wrappers.

### Your executable is a SQLite database
2026-08-24 · [Post](https://simonwillison.net/2026/Aug/24/your-executable-is-a-sqlite-database/) · tags: `c`, `linux`, `sqlite`

Farid Zakaria demonstrates a Linux technique where a SQLite database file doubles as a directly executable binary by embedding ELF components (code, symbols, etc.) into SQLite tables and setting the file's 4-byte application ID to `SELF`. The kernel can be taught to route execution through a custom `self-exec` interpreter via `binfmt_misc`, making the whole thing transparent. It's a niche systems trick but thought-provoking for reproducible packaging — the ELF format living inside a queryable relational store is genuinely novel.
