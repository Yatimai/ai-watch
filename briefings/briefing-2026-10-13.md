## 🔬 Research

### S-Space: Exploring Spatial Workspace in Multimodal Language Models
**270 upvotes** · Zhiyuan Shi et al. · [Paper](https://huggingface.co/papers/2610.13527)

This paper reverse-engineers how multimodal LLMs (MLLMs) handle spatial reasoning, identifying "S-Space": a linear subspace within object-token representations that continuously encodes X, Y, and depth coordinates. Crucially, this space is intrinsic — it's active even under non-spatial prompts — and acts as an internal workspace where perception, reasoning, and verbal output each tap into it independently via causal interventions. The diagnostic value is significant: the paper identifies a concrete bottleneck (viewpoint transformation, not perception) that explains many spatial reasoning failures, giving practitioners a principled direction for improvement.

### AgentSWE: Can Coding Agents Build the Agent You Actually Want?
**199 upvotes** · Jiahao Wang et al. · [Paper](https://huggingface.co/papers/2610.13361)

AgentSWE is a 25-task benchmark targeting the full agent development lifecycle — creation, editing, and optimization of agent codebases from natural-language requirements. The key finding: no current coding agent reliably delivers what it was asked for; the gap between what a builder *demonstrates* on visible test cases and what it *delivers* on held-out cases is the norm. Recurring failure modes include overfitting to example cases, hollow runtime behaviour behind superficially complete code, and unsupported completion claims — a sobering baseline for anyone relying on LLM-built agents in production.

### GroundingPI: A Grounding Foundation Model towards Physical Intelligence with Visual Primitives
**192 upvotes** · Qize Yu et al. · [Paper](https://huggingface.co/papers/2609.39601)

GroundingPI is a 4B-parameter vision-language grounding model that outputs quantized point and box coordinates, trained with a combination of multimodal pretraining, SFT, and GRPO reinforcement learning. It achieves 73.68% average across 34 benchmarks and 44 baselines, edging out the larger GPT-6 Astra (71.54%). As a visual backbone for downstream tasks, it improves robotic manipulation on RoboTwin 2.0 by up to 24.8% over the strongest competitor, and matches full-data baselines with only 50% of demonstrations on RoboCasa-GR1 — making it a strong case for dedicated perceptual pretraining as a foundation for physical AI.

## 📡 Analysis

### Quoting Geoffrey Huntley — Pre-commit hooks as agentic guardrails
2026-10-13 · [Post](https://simonwillison.net/2026/Oct/13/geoffrey-huntley/) · tags: `coding-agents`, `agentic-engineering`, `git`, `llms`

Huntley shares a concrete pattern for keeping coding agents on the rails: rather than patching `AGENTS.md` (which drifts), write a pre-commit hook that detects when an agent bypasses your diagnostics library and injects a corrective prompt directly into the commit flow. The takeaway is practical: git hooks are a lightweight, LLM-agnostic enforcement layer for agentic code discipline that doesn't require the agent to cooperate upfront.

### Hello Python 3.15, goodbye 3.10, and now I can use 3.11
2026-10-12 · [Post](https://simonwillison.net/2026/Oct/12/python-3-15/) · tags: `python`, `profiling`, `sqlite`, `uv`

Python 3.15 ships three standout features: **explicit lazy imports** (PEP 810, `lazy import json`), which directly solve slow CLI startup caused by heavy plugin dependencies; **unpacking in comprehensions** (PEP 798); and a built-in **sampling profiler** called Tachyon (`profiling.sampling`), previously available only via third-party tools like py-spy. Willison specifically flags lazy imports as a practical win for plugin-heavy CLI tools, and dropping 3.10 support means the ecosystem can now freely adopt 3.11+ syntax and performance improvements.

### web-edit 0.1a0 — Browser-based file editor for Tailscale-connected agents
2026-10-12 · [Post](https://simonwillison.net/2026/Oct/12/web-edit/) · tags: `projects`, `python`, `ai`, `tailscale`, `codex`

Willison built and released `web-edit`, a lightweight Python web app (using CodeMirror 6) that lets you browse and edit files in a folder over a Tailscale network — so an agent can spin it up and the human can edit sensitive files from a phone without ever passing credentials through the LLM. It's a small but sharp example of the emerging pattern: humans and agents sharing a workspace where some operations (credential editing, secret management) deliberately bypass the LLM for security reasons.
