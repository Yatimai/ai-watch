## 🔬 Research

### Turns Matter: Advancing Streaming Video RL via Turn-Level Credit
**90 upvotes** · Shuai Dong et al. · [Paper](https://huggingface.co/papers/2611.06728)

Streaming video models must decide turn by turn whether to respond or keep watching — but current GRPO-based RL approaches assign a single reward across the whole trajectory, which blurs which decisions were actually good. **TurnWise** fixes this with per-turn credit assignment using silence-completed prefix scoring and a turn-mean policy optimization that weights response and silence decisions equally regardless of output length. The result: better streaming policies without needing a learned critic or extra rollouts. Directly relevant for anyone building real-time video agents or interactive multimodal systems.

### From Pixels to Actions — Towards Native Vision-Language-Action Policies
**55 upvotes** · Weichen Fan et al. · [Paper](https://huggingface.co/papers/2611.06918)

Standard VLA models freeze visual computation before action reasoning starts, discarding fine-grained signals (geometry, depth, boundaries) that matter most for manipulation. **NEO-VLA** removes the visual encoder entirely: images are tokenized via lightweight patch convolutions and co-evolve with language through the backbone, letting a flow-matching action expert tap representations at any depth. Layer-wise probing shows action-critical signals often peak well *before* the final layer — meaning encoder-based designs systematically throw away useful information. This is a strong architectural argument for encoder-free designs in embodied AI.

### Think Less, Locally: Local Preference Learning for Reasoning Compression
**54 upvotes** · Muyao Yuan et al. · [Paper](https://huggingface.co/papers/2611.04814)

Large reasoning models over-think: they keep generating chain-of-thought tokens long after they have enough information to answer. **LoCo** targets this at the state level — it identifies candidate overthinking moments in a model's own traces, regenerates shorter verified continuations from those exact states, and trains on the resulting preference pairs with DPO. On math benchmarks, it cuts completion length by **41–45%** with maintained or improved accuracy; it also transfers to code generation (23–36% shorter) despite training only on math. Code and model are promised at [github.com/MuyaoYuan/LoCo](https://github.com/MuyaoYuan/LoCo).

## 🛠 Tools

### NVIDIA/auto-ontology — Semantic graph reasoning layer for LLM/agent workflows
**2707 stars/day** · [Repo](https://github.com/NVIDIA/auto-ontology)

NVIDIA's new Apache 2.0 open-source library builds enterprise knowledge graphs from metadata and exposes them to agents via MCP, CLI, and API. It reconciles inconsistent metric/entity definitions across systems and validates generated SQL queries against certified lineage — directly targeting the reliability problem in agentic analytics. With 6.6K stars and active development, it's positioned as NVIDIA's answer to grounding LLM agents in trusted, explainable enterprise data. Currently not accepting external contributions.

---

### vercel-labs/agent-desktop — Computer use for AI agents via the accessibility tree
**2173 stars/day** · [Repo](https://github.com/vercel-labs/agent-desktop)

A Vercel Labs Rust/C CLI that lets AI agents see and control desktop apps on macOS, Windows, and Linux — without screenshots or pixel-matching. It reads each app's OS accessibility tree, returns it as JSON with actionable refs, and the agent loops through click/type/observe cycles; there is no model inside the tool. Available via `npm install -g agent-desktop`, it reaches 16K+ stars and fills a gap for agents that need to operate native GUIs rather than just web interfaces.

**2053 stars/day** · [Repo](https://github.com/mattpocock/skills)

## 📡 Analysis

### datasette-agent 0.5a0
*2026-11-03* · [Post](https://simonwillison.net/2026/Nov/3/datasette-agent/) · tags: `projects`, `datasette`, `datasette-agent`

The headline feature is a **panel** mode: the agent chat can now float alongside any Datasette page (table, query, etc.) rather than occupying a separate view. Combined with `datasette-apps`, this means you can prompt a database-backed custom app into existence and then iteratively modify it from the chat panel sitting right next to it — a tight vibe-coding loop directly on top of your data. Try it live at [agent.datasette.io](https://agent.datasette.io).
