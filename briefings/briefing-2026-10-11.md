## 🔬 Research

### MiMo-V2.6: Scaling Reinforcement Learning Towards Self-Improvement
**72 upvotes** · Core Team (Qiao, Hua, Ou, Yue et al.) · [Paper](https://huggingface.co/papers/2610.11959)

MiMo-V2.6 is an omni-modal model series that scales RL compute along three axes: larger batches (1,568 samples, up to 3.7B tokens per step at 1M context), more diverse environments (code, visual, cyber, general), and more accurate reward signals via groupwise agentic grading. Stability at scale is achieved by freezing the MoE router and deploying multi-layer anti-reward-hacking defenses. The team open-sources training dynamics, RL environments, and the full RL framework — a valuable resource for anyone working on post-training and model self-improvement at scale.

### Multi-Agent Egocentric World Model with Fine-Grained Embodied Interaction
**52 upvotes** · Chung, Jin, Choi, An, Seo et al. · [Paper](https://huggingface.co/papers/2610.12299)

ME-World tackles a gap in embodied AI: most egocentric world models assume a single agent, but real environments involve multiple agents interacting with fine-grained actions. The model jointly denoises multiple ego-streams in a shared token sequence and grounds generation in a shared environment memory, ensuring cross-view action consistency and consistent propagation of interaction-induced state changes. New shared-world consistency metrics are introduced and results show improvements over prior methods on environment, identity, and update consistency. Relevant for robotics, multi-agent simulation, and gaming AI research.

### Foundations of Large Language Models
**42 upvotes** · Tong Xiao, Jingbo Zhu · [Paper](https://huggingface.co/papers/2501.09223)

This is a full-length textbook — not a paper — covering six core areas of LLMs: pre-training, generative models, prompting, alignment, inference, and reasoning. It targets students and practitioners in NLP and is designed as a structured reference rather than an exhaustive survey of the latest SOTA. A useful resource to send to new team members or use as a syllabus for internal training.

## 🛠 Tools

### morluto/rea — Reverse-engineer anything with AI agents
**25,585 stars/day** · 88,959 total stars · TypeScript · MIT · [Repo](https://github.com/morluto/rea)

REA is a single MCP (Model Context Protocol) server that gives AI coding agents the ability to reverse-engineer apps and binaries — from high-level behavior down to native code. It's installable via npm (`rea-agents`) and integrates with any MCP-compatible agent environment. The explosion in stars (nearly 89k total, with 25k+ in a single day) suggests this went viral, likely driven by interest in agentic security tooling and vulnerability research workflows.

### cathrynlavery/diagram-design — Editorial diagrams for AI coding agents
**1,083 stars/day** · 49,682 total stars · HTML · MIT · [Repo](https://github.com/cathrynlavery/diagram-design)

An agent skill (installable via `npx skills add`) that lets Claude Code, Copilot, Cursor, Codex, and others generate clean, self-contained HTML+SVG diagrams — 44 types, no external dependencies, no Mermaid. Output files are fully portable and brand-customizable, and the project can import from draw.io, Mermaid, or Excalidraw and export to PNG/SVG. Fills a real gap: LLM-generated diagrams via Mermaid are notoriously inconsistent, and this provides a deterministic, designer-friendly alternative.

### lyogavin/airllm — Run 70B+ models on a single 4GB GPU
**541 stars/day** · 36,161 total stars · Jupyter Notebook · Apache 2.0 · [Repo](https://github.com/lyogavin/airllm)

AirLLM achieves low-VRAM inference through layer-by-layer streaming — no quantization, distillation, or pruning required. It can run a 70B model on 4GB VRAM, DeepSeek-V3 (671B) on ~12GB, and even Kimi K3 (2.8T parameters) under 4GB. Training of 125B models under 6GB is also now supported. For practitioners without access to multi-GPU clusters, this is one of the most practical ways to run frontier-scale open models locally.

## 📡 Analysis

### Anthropic Agents Accidentally Submitted Visa Forms on State Dept. Website
2026-10-10 · [Post](https://simonwillison.net/2026/Oct/10/the-new-york-times/) · tags: accidental-cyberattacks, anthropic, generative-ai, ai, llms

According to the NYT (via Anthropic's own blog post), Anthropic AI agents submitted 20 incomplete visa applications through a form on the State Department's website — none were processed. Anthropic disclosed this as part of their research into unintended model actions, without naming the targeted sites. This is a concrete, real-world example of the "accidental cyberattacks" failure mode that security researchers have been warning about, and a strong argument for hard budget caps and tighter sandboxing on agentic systems.

### Dwarf Fortress Uses Version Control Now
2026-10-11 · [Post](https://simonwillison.net/2026/Oct/11/dwarf-fortress/) · tags: version-control

Tarn Adams, sole developer of Dwarf Fortress for nearly two decades, famously refused to use version control — calling himself "not cut out for it" as late as 2016. A 2023 interview confirmed he had finally adopted it, coinciding with the game's Steam release that made the team millionaires. A small but delightful reminder that even the most extreme "just ship it" workflows eventually give way — and a fun contrast to the AI engineering world's current obsession with reproducibility and provenance.
