### Look Only When Needed: Certificate-Guided Visual Routing for Efficient Diffusion VLMs
**101 upvotes** · Donghyeon Cho, Joowon Kim, Seungho Shin, Eunho Yang · [Paper](https://huggingface.co/papers/2610.36671)

Diffusion vision-language models (DVLMs) waste enormous compute by reprocessing visual tokens — which represent 89–97% of all input tokens — at every denoising step, even when the image isn't influencing the output. LOWN addresses this by checking at each step whether the image-free prediction matches the last image-conditioned one; if it does, the image is skipped and the "certified" tokens are unmasked directly. With no training and no tuned threshold, LOWN retains 99.6% of LLaDA-V's benchmark score while cutting decoding FLOPs to just 35.3% on average. It also composes with KV-caching and visual token pruning for additional gains.

### A-RSI: Adaptive Task Refresh for Zero-Data Multimodal Self-Improvement
**68 upvotes** · Yu Liu, Youxing Li, Yuedong Tan, Zhiwei Yang, Zihan Su · [Paper](https://huggingface.co/papers/2610.38568)

Most recursive self-improvement methods focus on *what* to generate next but ignore *when* stale experience starts to hurt training. A-RSI monitors reward variance and accuracy in training logs to automatically refresh its task pool when the learning signal plateaus, without touching validation or test data. Tasks and their verifiable reference answers are generated entirely by the model itself via a library of programs — no human labels or external training examples. On an eleven-benchmark suite, this raises the performance average from 57.77 to 61.05 using only 800 fresh tasks.

### Proving and Improving the Platonic Representation Hypothesis with JEPAs
**60 upvotes** · Randall Balestriero, Yann LeCun · [Paper](https://huggingface.co/papers/2610.39302)

This paper turns the Platonic Representation Hypothesis — the conjecture that models trained on different modalities converge to the same world representation at scale — into a formal theorem for Joint-Embedding Predictive Architectures (JEPAs). The key insight: next-token prediction is a JEPA with poor "views" (adjacent document fragments), which is why LLMs need massive scale to align with vision encoders. Empirically, good views require 42× fewer training samples to reach the same cross-modal alignment, and a 109M-parameter text JEPA beats every evaluated LLM up to 72B parameters on alignment with DINOv2 and CLIP. A single rotation matrix between independently trained encoders is sufficient to build a zero-shot image captioner (CIDEr 0.838 on COCO).

### How We Took Over ChatGPT Accounts
2026-10-31 · [Post](https://simonwillison.net/2026/Oct/31/how-we-took-over-chatgpt-accounts/) · tags: `iframes`, `javascript`, `sandboxing`, `security`, `xss`, `openai`, `chatgpt`, `content-security-policy`

Parameter Labs documented a multi-step exploit against ChatGPT's "HTML previews" (formerly Canvas): a sandboxed iframe could send a `postMessage` to trigger MathLive's virtual keyboard, whose `innerHTML`-based handler allowed injecting an unsandboxed iframe; CSP was bypassed by reflecting JavaScript through the YouTube oEmbed endpoint, giving full script execution on the ChatGPT origin. The attack chain ends with private data exfiltration or account takeover via any shared ChatGPT URL. OpenAI patched the vulnerability and paid a $5,000 bounty — which Simon notes seems low for a flaw this serious.

### dbreunig/nesformer — A working NES emulator baked into an LLM's weights
2026-10-30 · [Post](https://simonwillison.net/2026/Oct/30/nesformer/) · tags: `games`, `ai`, `generative-ai`, `llms`, `qwen`

Drew Breunig used Claude Opus 5.5 to fine-tune Qwen3.5-4B so that the model's weights encode a functional 6502 CPU emulator capable of running actual NES ROMs (including Super Mario Bros). The project was prompted almost entirely through natural language instructions to Opus, which independently found a 15-year-old NES CPU conformance test suite to validate correctness. It's a striking proof-of-concept that transformer weights can host deterministic state machines, even if execution speed is far below real-time.
