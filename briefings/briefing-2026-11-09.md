## 🔬 Research

### From Autonomous Agents to Cognitive Symbionts: Toward AI-Augmented Human Intelligence
**120 upvotes** · Hao Fei · [Paper](https://huggingface.co/papers/2611.05376)

This position paper argues that the dominant "autonomous agent" framing misses a second equally important direction: AI that amplifies a specific human rather than replacing them. The proposed concept of a **cognitive symbiont** — a lifelong, embedded, real-time, private companion that senses, remembers and thinks *alongside* a person — frames a new research paradigm called AI-Augmented Human Intelligence (AHI). The paper maps a full design space (sensing → keeping → understanding → acting → growing) and critically addresses governance risks: covert exam assistance, social pressure to adopt, and erosion of unaided cognitive skills. It's a timely conceptual anchor for anyone building personal-AI or wearable-AI products.

### Decoupled Predictive Decision Making: A Shared Conditional Predictor for Agents
**81 upvotes** · Lang Mo et al. · [Paper](https://huggingface.co/papers/2611.02075)

DPDM separates *semantic knowledge* (handled by a frozen LLM encoder, e.g. Qwen3.5-27B) from *empirical inference* (handled by a frozen general-purpose predictor called LimiX-2), letting agents learn from deployment history without fine-tuning either model. Across 50 benchmarks, mean accuracy jumps from 78.80% (few-shot prompting) to **84.92%**; on tool-use tasks (BFCL, ToolSandbox), absolute gains reach **+34%** and **+28.9%** respectively. This matters because it turns "learning from experience" into an independently improvable capability that can be dropped into any agent stack.

### SplatAnything: Gaussian Spacing Normalization for Feed-forward 3DGS across Arbitrary Scenes
**59 upvotes** · Hao Yu et al. · [Paper](https://huggingface.co/papers/2611.08264)

Feed-forward 3D Gaussian Splatting models struggle when reconstructing scenes at very different scales because Gaussian density varies wildly while only the global radial statistic is normalized. SplatAnything fixes this with **GSNorm**, which canonicalizes the spacing between neighboring Gaussian centers, giving the supervision signal a consistent spatial reference. The authors also release a rigorous benchmark spanning diverse datasets, sparsity levels, and extrapolated viewpoints — a useful contribution in itself for the 3DGS community. State-of-the-art results are especially pronounced under large scale and viewpoint variation.

## 🛠 Tools

### milind-soni/OpenMausBot — Open-source chat app where every contact is an AI agent
**1589 stars/day** · [Repo](https://github.com/milind-soni/OpenMausBot)

OpenMausBot (19 k ⭐ total, still climbing fast) is a local-first Electron app (macOS/Windows/Linux) that presents AI agents — Claude or Codex running under the hood — as chat contacts, each with its own personality, model, and sandboxed cloud VM. It positions itself as an open-source alternative to Grok Bot, Meta Muse, OpenAI Dots, and Manus Cue. The bring-your-own-model approach and VM-per-bot isolation make it a practical self-hosted option for teams wanting autonomous agents without vendor lock-in.

### vercel-labs/agent-browser — Rust CLI for headless browser automation in AI agents
**914 stars/day** · [Repo](https://github.com/vercel-labs/agent-browser)

`agent-browser` is a native Rust CLI (48 k ⭐, Apache-2.0) that exposes a browser to an AI agent one shell command at a time: `snapshot` returns the page as a compact accessibility tree with element refs (e.g. `@e1`), and the agent acts on a ref, re-reads the page, and repeats. Because the browser stays open between calls, each step is a cheap short shell invocation — no persistent process to manage. Available via `npm install -g agent-browser` or Homebrew, making it easy to drop into any agent pipeline.

### Hide your slop PR descriptions behind `<details><summary>`
*2026-11-09* · [Post](https://simonwillison.net/2026/Nov/9/details-summary/) · tags: `github`, `html`, `markdown`, `ai`, `coding-agents`, `llms`

Simon describes a workflow fix for a real-world pain point: AI coding agents (Claude Code, Codex) write accurate but dense PR descriptions that *read* like slop and get skimmed. His solution is to put a short human-curated paragraph at the top and collapse the full agent-written essay inside an HTML `<details><summary>` block — which GitHub Markdown renders natively. This keeps all the information accessible while restoring a human editorial signal at first glance, a low-friction pattern immediately reusable by any team using coding agents.

### parse_number() as a SQLite extension: C vs Rust
*2026-11-08* · [Post](https://simonwillison.net/2026/Nov/8/sqlite-parse-number-c-vs-rust/) · tags: `c`, `sqlite`, `rust`, `claude`

Simon used Claude Opus 5.5 to build four implementations of a `parse_number()` SQLite extension (strips `$`, `%`, `,` from strings) in C and Rust, then benchmarked them. The optimized C version using Clinger's fast-path decimal parser won at **16–19 ns/row** (~2× faster than Rust, far faster than SQL `replace()`), while the Rust binary was 20–23× larger (298–321 KB vs 14 KB for C). The post also shows Claude producing a formatted research report from the investigation — a neat example of AI-assisted applied systems research with concrete, reproducible numbers.
