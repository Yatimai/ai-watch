## 🔬 Research

### Compile by Training: Turning Natural-Language Specifications into Local Neural Functions
**314 upvotes** · Yuntian Deng, Pengyu Nie, Stuart Shieber · [Paper](https://huggingface.co/papers/2609.04199)

Rather than routing every inference call to a large remote API, this approach "compiles" a natural-language task description into a small, reusable neural adapter trained offline using teacher-generated examples. The resulting function runs fully locally, can be versioned and composed like code, and achieves 83.6% semantic accuracy on FuzzyBench-Hard — a benchmark where the fast "Program-as-Weights" compiler scored zero exact matches. The trade-off is compile time (~1 minute vs. seconds), which is acceptable for stable, recurring text functions. Practical demos include a multi-site web helper, a language-controlled 3D avatar, and an English↔Claudish translator.

### Terminal-Universe: Turning Agent Trajectories into Scalable Terminal Environments
**268 upvotes** · Jie Wu, Zhenru Zhang et al. · [Paper](https://huggingface.co/papers/2609.04148)

Post-training code agents requires executable environments, not just frozen trajectory logs — yet environments are rare. Terminal-Universe replays file-operation histories from existing trajectories to reconstruct the workspaces agents originally operated in, then synthesizes new tasks from those workspaces along two axes: breadth (cross-codebase queries) and depth (multi-round iterative sessions). Applied to public terminal-agent trajectories, the framework produces 37,300 task-sufficient environments. Fine-tuning Qwen3.5-27B on this corpus yields +11.9 points on Terminal-Bench 2.1 (single-round) and +13.8 points on EvoCode-Bench v2 MT@4 (multi-round).

### LLaDA-Image: Building Strong Image Generators with Fully Open Training Recipes
**226 upvotes** · Chuyan Chen, Haoxing Chen et al. · [Paper](https://huggingface.co/papers/2609.03796)

LLaDA-Image pairs a 6B Diffusion Transformer trained from scratch with a frozen vision-language module built on the LLaDA2.0-Mini diffusion LM backbone, trained on 220M samples (98% real images). It sets a new open-source state-of-the-art on Qwen-Image-Bench with scores of 53.53 (English) and 53.38 (Chinese), and distills into a **LLaDA-Image-Turbo** variant that runs in just 2–4 sampling steps. Crucially, weights, training code, and detailed recipes are all released, making this a rare fully reproducible large-scale image generation baseline.

### DietrichGebert/ponytail — Minimal-footprint heuristics for AI coding agents
**2,845 stars/day** · 128k total stars · [Repo](https://github.com/DietrichGebert/ponytail)

Ponytail injects "lazy senior dev" reasoning into AI agents: before writing code, ask whether the problem can be solved with less code, a library call, or nothing at all. Compatible with 20+ agents (Claude Code, Codex, Cursor, etc.), available as an npm package (`@dietrichgebert/ponytail`) under MIT. With 128k stars and 2,845 gained in a single day, it clearly resonates with engineers frustrated by agents that generate sprawling boilerplate solutions.
