## 🔬 Research

### From Autonomous Agents to Cognitive Symbionts: Toward AI-Augmented Human Intelligence
**104 upvotes** · Hao Fei · [Paper](https://huggingface.co/papers/2611.05376)

This position paper argues that Physical AI has two equal frontiers: embodied robots *and* AI-augmented humans (AHI). It introduces the concept of a **cognitive symbiont** — a lifelong, embedded, real-time personal AI companion that senses what you sense, retains your context across years, and assists at the right moment without friction. The core problem being addressed is the "cognitive gap": the delta between what a person *could* bring to a situation and what their working memory can actually hold. The paper also tackles governance concerns, from covert exam assistance to social pressure for universal adoption.

### VFlash: Fast, Accurate Visual Planning via Flash Primitive Decoding
**104 upvotes** · Yu-Cheng Chou et al. · [Paper](https://huggingface.co/papers/2611.08449)

Autoregressive VLMs generate visual plans (points, bounding boxes, trajectories) one token at a time, making them too slow for real-time robotics. VFlash introduces **Flash Primitive Decoding**: a lightweight drafter that predicts an entire spatial primitive in a single forward pass, yielding ~**25× faster generation** for 3D point motion forecasting. A world-action model conditioned on VFlash plans reaches **70.2% average success** across four MolmoSpaces task suites vs. 62.6% for the autoregressive baseline, with no loss in spatial accuracy.

### SLA: Scaling Spatial-Language-Action Model via Continual Pre-training
**84 upvotes** · Fuhao Li et al. · [Paper](https://huggingface.co/papers/2611.08373)

Most VLA models inherit 2D visual representations and only add spatial supervision at fine-tuning time — a bottleneck for 3D manipulation. SLA extends continual pre-training (starting from a pi0.5 policy) to jointly optimize action prediction and alignment with a frozen 3D perception teacher, without touching the inference architecture. Key ingredients include feature-dependent gates for multi-layer embedding aggregation, support for heterogeneous depth/calibration annotations, and probabilistic state dropout to prevent trajectory overfitting. This matters because spatial understanding becomes a reusable foundation capability rather than a task-specific add-on.

## 🛠 Tools

### milind-soni/OpenMausBot — Open-source chat-app agent platform
**1,437 stars/day** · [Repo](https://github.com/milind-soni/OpenMausBot)

OpenMausBot (formerly OpenGrokBot) is a local-first, bring-your-own-model alternative to Grok Bot, Meta Muse, OpenAI dots, and Cue by Manus. Each "contact" in the sidebar is a real agent (Claude or Codex) with its own personality, model, and sandboxed cloud VM. Built on TypeScript + React 19 + Electron, it runs on macOS, Windows, and Ubuntu, and targets developers who want agent workflows without vendor lock-in. At 17 k total stars and an active push today, it's clearly hit a nerve.

---

### vercel-labs/agent-browser — Browser automation CLI for AI agents
**812 stars/day** · [Repo](https://github.com/vercel-labs/agent-browser)

A native **Rust** CLI (installable via `npm install -g agent-browser`) that gives an AI agent a persistent browser it can drive one shell command at a time. Pages are returned as a compact **accessibility tree** with stable element refs (`@e1`, `@e2`…), so the agent reads, acts, reads again — no Playwright boilerplate required. With 47 k total stars and an Apache-2.0 license, it's become a de-facto standard for agentic web scraping and form-filling pipelines.

### anthropics/skills — Anthropic's official Agent Skills library
**793 stars/day** · [Repo](https://github.com/anthropics/skills)

Skills are self-contained folders (`SKILL.md` + scripts + resources) that Claude loads dynamically to handle specialized tasks — from brand-consistent doc generation to MCP server scaffolding. This public repo (189 k total stars) ships the same skills that power Claude's native document capabilities (`docx`, `pdf`, `pptx`), plus community-contributed ones. It's the reference implementation for the open **Agent Skills** standard at agentskills.io, making it directly relevant for anyone building Claude-based workflows.

### Datasette #3046: Firefox silently prefetches entire next-page results via `link: rel=next`
2026-11-07 · [Post](https://simonwillison.net/2026/Nov/7/link-rel-next/) · tags: `firefox`, `html`, `mozilla`, `datasette`

Simon discovered that Firefox auto-prefetches the next paginated page whenever a server sends a `link: rel="next"` HTTP header — causing Datasette to render and throw away full result pages for every table view. The underlying Firefox bug has been open for **24 years**, and Simon found he had personally complained about it in a 2002 blog post. The fix is to suppress that header for HTML responses in Firefox; relevant for anyone running paginated APIs or data-exploration tools.
