### Real2SimLab: A Unified Platform for Real-to-Simulation Transfer
**101 upvotes** · Yongchang Zhang et al. · [Paper](https://huggingface.co/papers/2611.34849)

Real2SimLab solves the N×M integration problem in real-to-simulation research: rather than each team wiring their method to each benchmark separately, this unified platform runs any method and scores its output using each benchmark's own original scorer. It currently supports 47 coding agents and 5 non-agent methods across 6 benchmarks, plus a data pipeline that generates training data and reward annotations while carefully avoiding benchmark contamination. The accompanying **Awesome-Real2Sim** map catalogs nearly 300 papers in the field. Useful for anyone building or evaluating agents that must reconstruct simulations from video.

### Sage-Med: Scaling Medical Multimodal Intelligence
**82 upvotes** · Med Team (Ming Hu, Cheng Tang et al.) · [Paper](https://huggingface.co/papers/2611.34575)

Sage-Med-Preview is a 35B-parameter (3B activated) medical multimodal model trained on 322.7M curated records through a staged curriculum: medical pretraining → supervised fine-tuning → adaptive reinforcement learning. It scores 58.26% average across 31 public multimodal benchmarks, beating the best open-source medical model Hulu-Med-235B-A22B (50.99%) and general model Intern-S2-Preview (52.24%), and approaching GPT-6.2-Sol on several tasks. The paper also delivers a key empirical finding: simply scaling model size improves text capabilities but **not** multimodal visual perception — a crucial insight for teams designing medical AI pipelines.

### Mixture-of-Loops Transformer (MoLT)
**57 upvotes** · Lianghui Zhu et al. · [Paper](https://huggingface.co/papers/2611.34923) · [Code](https://github.com/hustvl/MoLT)

MoLT rethinks Looped Transformers — which reuse shared layers for greater expressivity — by introducing a Mixture-of-Loops Attention (MoLA) mechanism that selectively reuses keys and values as cross-loop memory. The flagship variant **U-MoLT** outperforms OLMo3 at 700M/1.5B/3B scale in 400B-token pretraining, achieving **1.7× validation token efficiency** at 700M while nearly matching non-looped OLMo3 inference latency (996.6 vs. 1000.6 ms). A second result — MoL-decoding beyond the training loop horizon — opens possibilities for dynamic test-time compute scaling.

### sqlite3_rsync: Database Remote-Copy Tool For SQLite
2026-11-26 · [Post](https://simonwillison.net/2026/Nov/26/sqlite3-rsync/) · tags: `sqlite`, `backups`

`sqlite3_rsync`, shipped experimentally in SQLite 3.47.0 (Oct 2024) and enhanced in 3.50.0 (May 2025), allows snapshot copies of a SQLite database **over SSH without needing a full local copy first** — solving the disk-space bottleneck that makes `VACUUM INTO` and the backup API impractical on small instances. It uses a hash-exchange protocol similar to rsync, retransmitting only changed pages. For engineers running SQLite in production on constrained servers (edge, embedded, small VMs), this is a practical backup primitive worth integrating now.
