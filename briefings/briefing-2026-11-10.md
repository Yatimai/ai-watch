## 🔬 Research

### Learning Heterogeneous Tactile Representation for General Dexterous Manipulation
**91 upvotes** · Han et al. · [Paper](https://huggingface.co/papers/2611.12806)

LingBot-Touch is a tactile foundation model that produces a unified representation across fundamentally different sensor types — piezoresistive, magnetic, and visuotactile — so that robot policy models don't need to be retrained per sensor. The resulting "tactile tokens" are plug-and-play into existing policy architectures, including diffusion policies and VLA models like π₀.₅. This matters because it decouples tactile learning from specific hardware, enabling cross-sensor data pooling to scale dexterous manipulation the same way vision-language data has scaled perception.

### SplatAnything: Gaussian Spacing Normalization for Feed-forward 3DGS across Arbitrary Scenes
**67 upvotes** · Yu et al. · [Paper](https://huggingface.co/papers/2611.08264)

Existing feed-forward 3D Gaussian Splatting models normalize depth in radial space, but the spacing between neighboring Gaussians still varies wildly across scenes, creating ambiguous training signals. SplatAnything introduces Gaussian Spacing Normalization (GSNorm) to canonicalize that spacing, yielding a more consistent spatial reference at prediction time. The method achieves state-of-the-art results especially under large scene-scale and viewpoint variation, with a new rigorous benchmark covering sparse inputs and extrapolated viewpoints.

### WorldFoundry: Towards Unified Infrastructure for World Intelligence
**50 upvotes** · Tian et al. · [Paper](https://huggingface.co/papers/2611.10771)

WorldFoundry is an open-source evaluation and inference framework targeting true world models — systems that maintain persistent state, respond causally to actions, and generate temporally coherent trajectories — rather than merely visually plausible video generators. The catalog already includes 270 model entries, 74 benchmarks, and 62 metrics across video, 3D/4D, embodied action, and interactive world systems. Its "evidence-aware scorecards" and durable artifact contracts make each evaluation claim traceable, addressing the reproducibility problem that plagues this space.

## 📡 Analysis

### Introducing Muse Ember — Meta's small efficient reasoning model
2026-11-10 · [Post](https://simonwillison.net/2026/Nov/10/muse-ember/) · tags: `ai`, `llms`, `llm-pricing`, `llm-release`, `muse`

Meta launched Muse Ember 1.0, their answer to Claude Haiku 5.5 and GPT-6 Luna, targeting agentic subtasks: tool calls, routing, extraction, and long document parsing. Pricing starts at $0.10/M input / $0.50/M output (≤200k tokens), but climbs steeply beyond that threshold — making it more expensive than Luna for very long contexts. Notably, Artificial Analysis places it on the efficiency Pareto frontier: no model scores higher intelligence per dollar-per-task at that tier, and Willison's SVG tests suggest quality comparable to Muse Wonder at 1/40th the price.

### Prompting Claude Fable 5.2 — Ownership framing changes code quality
2026-11-10 · [Post](https://simonwillison.net/2026/Nov/10/prompting-claude-fable-52/) · tags: `prompt-engineering`, `anthropic`, `claude-mythos-fable`

Anthropic's official Fable 5.2 prompting guide reveals a concrete, non-obvious finding: telling the model "this codebase is yours" causes it to refactor and deduplicate existing code roughly 5× more often than when ownership is left implicit. This is a rare case of a documented, quantified prompt-engineering technique backed by Anthropic's own testing — a useful one-liner to add to any coding agent system prompt.
