## 🔬 Research

### SO-Arena: Benchmarking the Capability Spectrum and Reliability of System One Models
**84 upvotes** · Lichen Li et al. (NUS) · [Paper](https://huggingface.co/papers/2611.15777)

SO-Arena benchmarks "System One" models (fast, non-chain-of-thought decision-makers) across 11 domains and 5 capability families, going beyond accuracy to measure *decision reliability* — specifically, stability under option-set changes and the ability to flag unanswerable questions. Evaluated across 21 models, the benchmark reveals a critical decoupling: the best-performing model on overall accuracy ranks only **7th in reliability**. This matters because production deployments depend on consistent, trustworthy outputs, not just peak benchmark scores.

### BirdDreams: Joint Perspective and BEV Video Generation for a Plausible, Reactive Driving World Model
**49 upvotes** · Junyoung Seo et al. · [Paper](https://huggingface.co/papers/2611.14815)

BirdDreams is an autoregressive driving world model that co-generates a standard perspective video and a bird's-eye-view (BEV) schematic video using two jointly-attending video diffusion transformers. The BEV stream handles vehicle positions and motion with less occlusion, while the perspective stream retains scene details like traffic signals; ego trajectory control is achieved by geometrically transforming the latest BEV frame. At inference it needs only a single camera image — no HD map, no vehicle state — and outperforms prior driving world models on PhysicalAI-AV and nuScenes in trajectory fidelity and plausible surrounding-vehicle motion.

### Scaling Mathematical Proof Supervision from Structured Textbooks
**46 upvotes** · Youqing Fang et al. · [Paper](https://huggingface.co/papers/2610.40394)

TOME-Math converts **2,118 university-level math textbooks** into ~380K structured proof-supervision records, preserving chapter order, proposition-proof links, dependency references, and source provenance — information discarded by conventional flat problem-solution datasets. Fine-tuning on TOME-Math yields a **+16.7 percentage point** improvement in unweighted mean score over the base model, outperforming all three public instruction-data baselines. The corpus will be released publicly, offering both a scalable supervision source and a framework for studying how data organization affects mathematical reasoning.

## 🛠 Tools

### GoogleChrome/modern-web-guidance-src — Embed modern web expertise into coding agents
**1,225 stars/day** · [Repo](https://github.com/GoogleChrome/modern-web-guidance-src)

Modern Web Guidance is a set of "skills" (installable via `npx modern-web-guidance@latest install`) that inject up-to-date web platform best practices, browser compatibility data, and anti-legacy-pattern rules directly into coding agents like Cursor, Copilot, or Claude. It is stewarded jointly by Google Chrome, Microsoft Edge, Mozilla Firefox, and MDN teams, making it unusually authoritative. For teams whose agents still generate `XMLHttpRequest` or outdated CSS patterns, this is a practical fix.

---

### alibaba/open-code-review — Production-grade LLM-powered code review at scale
**897 stars/day** · [Repo](https://github.com/alibaba/open-code-review)

Open-Code-Review is a hybrid code review tool written in Go that pairs deterministic rule pipelines with an LLM agent to produce precise, line-level comments. It ships with built-in multi-language rulesets covering NPE, thread safety, XSS, and SQL injection, and is compatible with OpenAI and Anthropic APIs. Having been battle-tested at Alibaba's scale, it's a credible option for teams wanting automated review that goes beyond linting without fully surrendering to pure LLM hallucination risk.

### ChromeDevTools/chrome-devtools-mcp — Full Chrome DevTools access for AI coding agents
**673 stars/day** · [Repo](https://github.com/ChromeDevTools/chrome-devtools-mcp)

This MCP server exposes Chrome DevTools capabilities — network inspection, console logs, performance traces, screenshots, Puppeteer automation — to any MCP-compatible agent (Claude, Cursor, Copilot, etc.). At **55,989 total stars**, it is already one of the most adopted MCP servers in existence. It's the missing link for agents that can read code but can't observe how it behaves at runtime in a real browser.
