## 🔬 Research

### Vidu S2: Real-Time Interactive, Editable, and Spatial Video Generation
**693 upvotes** · Jintao Zhang et al. · [Paper](https://huggingface.co/papers/2609.11638)

Vidu S2 ships two real-time models: **S2-Avatar** for interactive digital-character generation (720p, dynamic reference updates, dance instructions) and **S2-Editing** for live video stream editing (style, clothing, character, and background replacement). Both also support spatial video output. The real-time constraint at 720p is the headline here — most prior video editing pipelines are batch-only — and a live demo is already publicly accessible at vidu.com/vidu-stream.

### Atria Dawn: The Dawn of Agentic Superintelligence
**421 upvotes** · Honglin Guo et al. · [Paper](https://huggingface.co/papers/2609.15818)

Atria Dawn Preview is a foundation agentic language model trained via a **Verifiable Experience Pipeline** that ties tool use to executable environments with externally verified outcomes. Evaluated across 16 real-world benchmarks, it tops five of them and rivals frontier agents on the rest. The most striking finding from studying 769 task records across 56 participants: ~1/3 of AI-assisted tasks were rated infeasible without AI, and the human role is shifting from execution to **project-level guidance and oversight** — a data-backed case study of what genuine human-AI R&D co-authorship looks like in practice.

### ZGCM-1: A Fully Open and Extremely Efficient Foundation Model for Math and Agentic Search
**302 upvotes** · Jiyan He et al. · [Paper](https://huggingface.co/papers/2609.13356)

ZGCM-1 is a **fully open 7B dense model** trained from scratch, combining interleaved gated sliding-window + full attention, FP8 Muon optimizer, and a 256K context trained progressively (16K → 64K → 256K). Despite its size, it stays competitive with Qwen3-235B-A22B and GLM-5.1 on hard math and agentic search tasks, with a **~4.2× efficiency gain** in 16K pre-training time-to-loss. All weights (pre/mid/post-training stages), intermediate checkpoints, training code, data recipes, and W&B logs are open-sourced — making this one of the most transparent large-model releases to date.

## 🛠 Tools

### alibaba/open-code-review — Production-grade LLM-augmented code review
**3,215 stars/day** · [Repo](https://github.com/alibaba/open-code-review)

Written in Go, this hybrid tool combines deterministic rule pipelines with an LLM agent to produce precise **line-level code review comments** at Alibaba's internal scale. It ships a built-in multi-language ruleset covering NPE, thread-safety, XSS, and SQL injection, and is compatible with both OpenAI and Anthropic APIs. The battle-tested provenance from Alibaba's own engineering org makes it a credible alternative to purely LLM-based review bots, where hallucinated findings are a common failure mode.

### JustVugg/colibri — Run 744B–2.8T MoE models on consumer hardware
**1,532 stars/day** · ★34,576 · [Repo](https://github.com/JustVugg/colibri)

Colibri is a **pure-C, zero-dependency inference engine** that treats VRAM, RAM, and disk storage as a single unified memory hierarchy, streaming MoE experts from disk on demand. It currently supports nine model families including Kimi K3 (2.8T), GLM-5.2/5.3 (744B), DeepSeek V4.1 Flash (552B, with vision), and Qwen3.8-Flash-Next — each as a single C file behind a shared `coli chat/serve/web` frontend. The project's explicit goal is to make frontier-scale inference less dependent on scarce, expensive GPU clusters.

### cloudflare/security-audit-skill — Structured multi-phase security auditing for coding agents
**1,434 stars/day** · ★5,559 · [Repo](https://github.com/cloudflare/security-audit-skill)

This JavaScript skill turns a coding agent into a **six-phase security auditor**: reconnaissance → coverage-led hunting → candidate validation → structured JSON output → independent record verification → target-neutral reporting. Each finding is categorized as `confirmed`, `needs_validation`, or `rejected` with full source traces, validated against a JSON schema. It was the seed of Cloudflare's own internal fleet-wide vulnerability discovery harness, giving it real-world provenance beyond a toy demo.

### Gemini Live audio
2026-09-15 · [Post](https://simonwillison.net/2026/Sep/15/gemini-live/) · tags: `google`, `gemini`, `websockets`, `speech-to-text`, `llm-release`

Google released **Gemini 3.8 Live** and **3.8 Live Extended Thinking**, two speech-to-speech models analogous to OpenAI's GPT-Live family. Simon built a no-library browser UI that connects directly to Google's WebSocket endpoint (`wss://generativelanguage.googleapis.com/...`) using the Web Audio API — and notably, he used GPT-6 Astra Extra High to generate the implementation. The post doubles as a quick technical primer on the WebSocket API for anyone wanting to integrate Gemini Live into their own apps.

### The contagion of fear
2026-09-14 · [Post](https://simonwillison.net/2026/Sep/14/the-contagion-of-fear/) · tags: `ai`, `anthropic`, `bryan-cantrill`, `ai-ethics`

Bryan Cantrill responds to a viral tweet by former Anthropic employee Jacob Coxon, who confirmed that many Anthropic researchers believe AI could kill everyone "by the end of the decade." Cantrill's argument: vague claims about "bioweapons" and "critical infrastructure" from people who are not domain experts in those fields abuse the public's implicit trust in technical experts and spread unjustified fear. The piece is a useful counter-weight to doomer rhetoric, and Cantrill's core demand — that those making extinction claims provide rigorous, domain-specific evidence — is a reasonable standard to hold the discourse to.
