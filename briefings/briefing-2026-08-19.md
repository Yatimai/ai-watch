### StateM: Reaching 95.3% Raw Accuracy on Terminal-Bench 2.1 via Harness Scaling
**220 upvotes** · Ziheng Qin, Yaxin Lu, Zhangyang Atlas Wang, Kai Wang · [Paper](https://huggingface.co/papers/2608.15089)

StateM is an agent runtime that improves long-horizon task performance not by changing model weights, but by wrapping the agent in a structured execution harness (durable states, phase-local context, recoverable runbooks, versioned practices). On Terminal-Bench 2.1, it pushes GPT-5.6 Sol xhigh to 95.3% across 445 trials. The cost angle is striking: the same runtime applied to DeepSeek-V4 Flash costs ~$52 total versus $574 for the GPT-5.6 Sol reference, matching or beating it on most tasks. This "harness scaling" paradigm — optimizing the execution shell rather than the model — is a practical alternative to expensive fine-tuning or frontier-model upgrades.

### HarnessEval-W: Agentifying the Evaluation of Visual Worlds
**115 upvotes** · Weiliang Chen, Haowen Sun, Jun Gao, Jiawei Chi, Hanyang Wang · [Paper](https://huggingface.co/papers/2608.16859)

Current world-model benchmarks reduce a full video rollout to a scalar score with no reasoning chain, making it impossible to audit *why* a model failed. HarnessEval-W brings the agent-harness paradigm to evaluation: a parent agent decomposes each evaluation case, spawns specialized sub-agents with tailored diagnostic tools, then assembles their evidence into a transparent verdict tree. Applied to 18 world models over 330 cases, its judgments align closely with human preferences while producing verifiable, fine-grained diagnoses. For teams building generative video or simulation models, this offers a much more actionable signal than existing metrics.

### SA-MRPO: Saturation Aware Advantage Reweighting for Multi-Reward Policy Optimization
**87 upvotes** · Yixuan Wang, Yifei Chen, Haichao Zhang, Haozheng Luo, Xander Wu · [Paper](https://huggingface.co/papers/2608.16072)

When fine-tuning LLMs with multiple reward signals (e.g., correctness + format + safety), standard GRPO-style methods scalarize rewards before normalization, wasting gradient budget on already-solved objectives. SA-MRPO standardizes each reward independently and dynamically down-weights saturated objectives at the batch level, effectively redirecting training effort toward harder unsolved goals. On math reasoning benchmarks, it outperforms GDPO on the harder correctness objective in 12 of 15 comparisons, with up to +5% on AIME24 and +9.2% on AMC23 for adaptive reasoning. A low-cost drop-in improvement for any multi-reward RL post-training pipeline.

### Mojo🔥 is now open source
2026-08-18 · [Post](https://simonwillison.net/2026/Aug/18/mojo-is-now-open-source/) · tags: `open-source`, `python`, `mojo`

After promising an open-source release since May 2023, Modular has shipped Mojo 1.0 and released the compiler and toolchain under Apache 2. The language has pivoted away from being a strict Python superset — it is now its own GPU-optimized language with Python-inspired syntax, banking on AI-assisted migration tools to ease adoption. For ML engineers doing GPU work, this is worth watching as a potential alternative to CUDA C++ without the full Python runtime overhead.
