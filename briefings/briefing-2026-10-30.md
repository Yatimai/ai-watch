## 🔬 Research

### Intrinsic Distribution Matching (IDM)
**233 upvotes** · Deyuan Liu et al. (inclusionAI) · [Paper](https://huggingface.co/papers/2610.39633)

IDM improves one- and few-step text-to-image generation by decomposing the reverse-KL distillation field into a Gaussian moment component (means + per-coordinate std) and a non-Gaussian residual, adding an explicit moment loss on top of standard DMD score supervision. Crucially, it uses the generator's own EMA copy as the feature encoder, avoiding any external network like DINOv2. Tested on Z-Image-Turbo 6B and Qwen-Image 20B, IDM reaches 94.25% / 90.20% on Chinese and English LongText-Bench at only 2 network evaluations — the best results among compared methods at that compute budget. Useful baseline for anyone working on efficient diffusion distillation. [Code](https://github.com/inclusionAI/IDM)

### Falcon — Efficient Streaming Audio-Visual Speaker Extraction
**152 upvotes** · Wendi Sang, Kai Li et al. (Tsinghua) · [Paper](https://huggingface.co/papers/2610.32749)

Falcon is a causal, streaming model for isolating a target speaker's voice using both audio and a video face reference — designed for real-time, edge deployments. Compared to the causal AV-TFGridNet baseline, it cuts parameter count by **91.9%**, computation by **20.2×**, and GPU inference latency by **11.1×**, while still achieving SOTA on LRS2/LRS3/VoxCeleb2 benchmarks. The paper also releases **RealSSA**, a new realistic benchmark with 1–15 dynamic interfering speakers, near/far-field interference, and reverberation — a significant step up from the standard 2-speaker fixed setups. Relevant for anyone building real-time speech separation or video conferencing AI. [Demo & Code](https://cslikai.cn/Falcon/)

### A-RSI: Adaptive Task Refresh for Zero-Data Multimodal Self-Improvement
**144 upvotes** · Yu Liu et al. · [Paper](https://huggingface.co/papers/2610.38568)

A-RSI addresses recursive self-improvement without any external training data or human-written labels: the model generates its own multimodal tasks (via programs with verifiable answers) and monitors reward variation to decide *when* to refresh the task pool rather than just *what* to generate next. This "when" signal — derived purely from training dynamics — is the key novelty, preventing the model from overfitting stale tasks. Across an eleven-benchmark suite, the average score rises from 57.77 to 61.05 using only 800 fresh tasks, a lean improvement that underscores the value of adaptive data scheduling over brute-force generation.

## 🛠 Tools

### pbakaus/impeccable — Design vocabulary for coding agents
**2,299 stars/day** · Rust · [Repo](https://github.com/pbakaus/impeccable)

Impeccable is a set of slash-commands (`/polish`, `/bolder`, `/critique`, `/audit`) that give coding agents a shared design language, preventing the generic "Inter font + purple gradient + nested cards" output that AI code generators default to. Install via `npx impeccable install`, compatible with Claude Code, Cursor, Codex CLI, Copilot, Devin, Gemini CLI, and a dozen others. With **96k total stars** and a push as recent as this morning, it's clearly struck a nerve — the before/after screenshots in the README make the value proposition immediately tangible.

### Building a Multiplayer Game World with Autonomous Fable-class Agents
2026-10-29 · [Post](https://simonwillison.net/2026/Oct/29/how-i-built-the-most-ai-pilled-company-in-the-world/) · tags: agentic-engineering, coding-agents, claude-mythos-fable, game-design

Jacob Sansbury's writeup on Spawn describes a fully autonomous dev loop where a swarm of Fable 5.1-powered agents read production errors, file bugs, write fixes, and ship to production **hourly** — with an hour without a deploy treated as a SEV-0 incident. At **$3M/month in token spend** (30× payroll), it's an extreme data point on what frontier agentic systems can sustain today. Simon found it credible precisely because it's a game — higher-stakes software would surface the risks more painfully — but the architectural patterns (agent-owned incidents, 30-second rollbacks, self-filed bugs) are worth studying regardless.
