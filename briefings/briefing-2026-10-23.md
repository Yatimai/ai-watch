## 🔬 Research

### Making MLLM Latents Matter: Factor-Aware Predictive Learning for Cinematic Video Generation
**161 upvotes** · Yang, Wang, Zhao et al. · [Paper](https://huggingface.co/papers/2610.30926)

FAPL is a training framework that forces Video Diffusion Transformers to actually *use* multimodal LLM representations, rather than routing around them via native conditioning shortcuts. It targets three cinematic video tasks — sparse-to-video synthesis, factor-aware editing (character, scene, action, camera), and multi-shot generation — each addressed by dedicated learning signals. The key insight is to decouple MLLM feature grounding from factor control and temporal inference training, tackling them as complementary stages. Results consistently outperform baselines across all three tasks, making this relevant for anyone building controllable, long-form video generation pipelines.

### Deep Search in Real-World Web Environments
**144 upvotes** · Yu, Chen, Huang et al. · [Paper](https://huggingface.co/papers/2610.30181)

OpenDS-World is a 200-task benchmark for evaluating agents that must do autonomous, multi-step research on the *live* open web — handling diverse formats, file types, and interactive access mechanisms. The best frontier model scores only 39.0% accuracy, while human evaluators on 1,000 independent attempts averaged just 21.1%, suggesting the tasks are genuinely hard rather than trivially solved. Analysis of 12 models reveals persistent weaknesses in tool coordination and long-horizon search management. This is a timely, rigorous evaluation framework as deep-search agents proliferate in production settings.

### WeVisOne-VL: Unified Visual Perception from Objects to Pixels
**137 upvotes** · Liang, Pan, Li et al. (WeChat Vision) · [Paper](https://huggingface.co/papers/2610.31329)

WeVisOne-VL is a VLM from WeChat Vision that handles the full perception stack — detection, grounding, counting, OCR, segmentation, and alpha matting — via a single model trained with a three-stage curriculum SFT followed by mixed-task RL. It achieves this by injecting a lightweight pixel decoder through a special `<OBJ>` token, avoiding the bloated architectures of multi-model pipelines. The model leads across 30+ benchmarks on both object-level and pixel-level tasks and is released open-source. It's a direct challenge to the assumption that fine-grained pixel-level perception requires separate specialized models.

## 🛠 Tools

### cloudflare/security-audit-skill — AI coding-agent skill for multi-phase security audits
**2706 stars/day** · [Repo](https://github.com/cloudflare/security-audit-skill)

This is the open-source seed project behind Cloudflare's internal vulnerability discovery harness, structured as a six-phase automated audit: recon, coverage-led hunting, candidate validation, structured output, independent record verification, and target-neutral reporting. Each finding gets a machine-readable verdict (`confirmed`, `needs_validation`, or `rejected`) with a full source trace, and multiple runs against the same repo are additive. At 40,823 total stars, it's already widely adopted; the high daily star rate likely reflects Cloudflare's companion blog post on building a vulnerability harness. Directly usable with any coding agent that supports skills.

### anthropics/knowledge-work-plugins — Open-source plugins for Claude Cowork
**643 stars/day** · [Repo](https://github.com/anthropics/knowledge-work-plugins)

Anthropic open-sourced 11 role-specific plugins (productivity, sales, customer support, product management, and more) for Claude Cowork and Claude Code, each bundling skills, connectors, slash commands, and sub-agents for a given job function. Useful as production-ready starting points or reference implementations for anyone building agentic workflows on top of Claude.

### NVIDIA/OpenShell — Secure, kernel-enforced runtime for autonomous AI agent fleets
**211 stars/day** · [Repo](https://github.com/NVIDIA/OpenShell)

OpenShell (Rust, Apache 2.0) gives autonomous agents real capabilities — file access, package installation, API calls, credential use — while enforcing per-agent policies at the kernel level: every syscall, file access, and network connection is checked against a declared policy before it executes. An additional layer of formal verification validates policy changes before they are applied. At 18,275 stars and actively pushed today (v0.1.x stable), it addresses a genuine gap: most agent runtimes today offer either no isolation or heavy container overhead. Directly relevant to anyone deploying multi-agent systems in production.
