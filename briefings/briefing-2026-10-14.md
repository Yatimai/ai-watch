## 🔬 Research

### Jeva: System One Models from First Principles
**114 upvotes** · Qi Li, Xinhua Wang · [Paper](https://huggingface.co/papers/2610.18773)

Jeva is a decision-native architecture for fast, low-latency inference that fixes four structural gaps in today's LLM-based classifiers: handling missing answers (null-awareness), being insensitive to option ordering (permutation-invariance), scaling to thousands of candidates without redefining outputs, and caching option representations across requests for latency gains. Unlike serialized-text prediction, Jeva uses a shared encoder for requests and options independently, feeding a compact decision stack, which enables cross-request reuse. The result is near-perfect null detection, zero decision flips under arbitrary permutation, and meaningful speed-ups at scale — a practically relevant baseline for any team building ranking or selection systems.

### Agent-Reflex: Teaching Language Agents to Act Reflectively
**107 upvotes** · Guanting Dong et al. · [Paper](https://huggingface.co/papers/2610.17953)

Agent-Reflex is a three-stage training framework to make LLM agents more robust to noisy tool feedback and user corrections — a common, underserved failure mode in production MCP deployments. It mines success/failure pairs to extract reusable "reflection meta-skills," then applies supervised fine-tuning and on-policy RL with those skills as guidance. Built on Qwen3-8B, it scores 58.6 overall on five long-horizon benchmarks and 29.1 on AgentNoiseBench, outperforming existing reflection and environment-scaling baselines. Code is available at [github.com/RUC-NLPIR/Agent-Reflex](https://github.com/RUC-NLPIR/Agent-Reflex).

### Urbex: Agentic Spatial Grounding for City-Scale 3D Scenes
**101 upvotes** · Yu Wang et al. · [Paper](https://huggingface.co/papers/2610.18356)

Urbex reframes city-scale 3D object grounding as an active spatial search rather than a pre-computed candidate ranking problem, making it viable for large outdoor scenes where proposal generation is prohibitively slow. A VLM agent navigates a multi-view environment, querying landmarks and zooming into sub-regions before committing a bounding box, with the tool-use policy trained via RL using smooth localization rewards. It achieves best-in-class Hit@1 and IoU on CityRefer and transfers zero-shot to STPLS3D-Refer, with no dependency on ground-truth instance proposals. This has direct implications for autonomous driving, urban robotics, and geospatial AI applications.

## 📡 Analysis

### Redesigning source control at Anthropic
*2026-10-13* · [Post](https://simonwillison.net/2026/Oct/13/redesigning-source-control-at-anthropic/) · tags: `git`, `migrations`, `version-control`, `anthropic`, `agentic-engineering`

Anthropic built **Scion**, a custom Git replacement, after AI-driven coding pushed their merge rate from ~2,500 to **30,000+ code changes per day** in just four months — generating a compressed working copy of 25 GB and ~25 million CI checkouts per day, making standard Git untenable. A team of seven shipped the migration from Git in five months; offline support was explicitly deprioritized since Claude is by far the heaviest user and is necessarily online. The post is a concrete data point on how agentic coding is forcing infrastructure rethinks at the very top of the stack.

### Quoting Geoffrey Huntley — Using git hooks to steer coding agents
*2026-10-13* · [Post](https://simonwillison.net/2026/Oct/13/geoffrey-huntley/) · tags: `coding-agents`, `git`, `agentic-engineering`

Geoffrey Huntley proposes using **pre-commit hooks as a prompt-injection mechanism** for coding agents: when the hook detects a bad pattern in the diff (e.g., bypassing a diagnostics module), it fails the commit and injects a corrective prompt directly into the agent's context. This is a clever, low-overhead technique to enforce architectural constraints on agent-generated code without modifying the agent's system prompt. As agentic code generation scales, these kinds of "guard rails at the VCS layer" patterns are likely to become standard practice.
