## 🔬 Research

### STEPQuant: When and Where Errors Matter in Delta-Rule Recurrent State Quantization
**91 upvotes** · Bingchen Yao et al. · [Paper](https://huggingface.co/papers/2609.38169)

Linear attention models (like Kimi-Linear and Qwen3.8) replace KV caches with fixed recurrent states, but quantizing those states naively causes cascading accuracy loss. STEPQuant allocates precision spatially (per key-row importance) and temporally (by memory lifetime), achieving near-FP32 accuracy under a 6-bit budget and beating uniform INT8 at 4-bit. Integrated into SGLang with custom GPU kernels, it delivers **5× recurrent-state compression** and cuts total serving memory by up to **68.7%** — a directly deployable win for anyone running linear-attention models at scale. Code is available on GitHub.

### Long-WAM: Scaling the Context of World-Action Models
**83 upvotes** · Wei Huang et al. · [Paper](https://huggingface.co/papers/2610.10528)

Long-WAM is a robot control framework that dramatically improves policy performance by extending video context history up to 19.2 seconds — but only when the video backbone was pretrained **autoregressively** (AR); bidirectional pretraining shows zero gain. This AR-pretraining finding is the key insight: longer history only pays off if the model is structurally wired to use it. On RoboCasa GR-1, success jumps from 63.3% to 78.7%, and on a dynamic cup-stacking task, Long-WAM achieves 95% success while Pi0.5 and Fast-WAM score 0/20. The system runs in real-time on hardware as modest as Jetson AGX Thor.

### Recursive Game Creator: An Agentic Product-Level Experience-Oriented Game Harness
**75 upvotes** · Jiajun Chen et al. · [Paper](https://huggingface.co/papers/2610.08621)

Recursive Game Creator is a multi-agent pipeline (Designer → Builder → Player → Reviewer) that iteratively refines generated games for *player enjoyment*, not just code correctness. The key innovation is a coding-native Player agent that executes programmatic gameplay policies — avoiding slow GUI-based evaluation — to collect diverse trajectories for the Reviewer. It achieves **77.89 overall on GameCraft-Bench** and a **53.2% strict task success rate on GameASG-Bench** (+34.1% over baseline), with a 93.4% runtime-check pass rate. A user study confirms higher playtime and satisfaction ratings.

### morluto/rea — Reverse-engineer anything with agents, down to native binaries
**7,744 stars/day** · 20,011 total ⭐ · [Repo](https://github.com/morluto/rea)

REA is a TypeScript MCP (Model Context Protocol) server that exposes reverse-engineering capabilities to AI agents — binary analysis, app behavior tracing, edge detection in runtime code — all in a single `npx rea-agents setup`.
