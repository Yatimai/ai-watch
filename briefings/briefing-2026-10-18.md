## 🔬 Research

### Waypoint-OPD: Transferring RL-Induced Policy Shifts via Gated On-Policy Distillation
**667 upvotes** · Bingxi Hou et al. · [Paper](https://huggingface.co/papers/2610.21601)

Standard policy-shift distillation transfers the difference between a teacher's log-probabilities before and after RL, but this "endpoint" shift can mask early and late training dynamics that partially cancel each other out. Waypoint-OPD introduces an intermediate checkpoint from the same RL run and gates the endpoint shift based on whether early and late policy preferences agree directionally. Evaluated with Qwen3-4B teachers and Qwen3-8B/14B/30B-A3B students across math and code reasoning, it tops all six domain–student settings with only one extra frozen-teacher scoring pass. Useful for any team distilling RL-trained reasoning models without wanting to pay the full compute cost of training students from scratch.

### MJev-Spatial: System One Spatial Intelligence via Native Attention Matching
**353 upvotes** · Luozheng Qin et al. · [Paper](https://huggingface.co/papers/2610.22276)

VLMs are slow at spatial tasks (relations, distances, locations) because they generate free-form text even when the answer space is tiny. MJev-Spatial reframes all three task types as classification, scoring candidates with the backbone's existing query/key projections — adding zero parameters and generating zero answer tokens. Built on Qwen3.5-4B and trained on 12.3M QA pairs, it scores 65.64% overall, ranks first on 7 of 12 spatial benchmarks, and runs 5.6× faster than the base autoregressive model. The 30.8% training-throughput gain from length-aware global batching and cross-GPU load balancing is also a practical takeaway for efficient multi-task training.

### OpenGCUA: Toward a Fully Open Stack for Generalist Computer Use
**316 upvotes** · Hanzhang Zhou et al. · [Paper](https://huggingface.co/papers/2610.22200)

Frontier computer-use agents like GPT-6 Astra are closed, making it hard to study or improve their design. OpenGCUA is a fully open generalist computer-use agent that integrates code execution so that intermediate results dynamically steer subsequent steps, replacing fixed harness rules with model-level decisions. On OSWorld-v2, their configuration raises mean partial score by +19.6 points and cuts reported steps per task by 53% relative to batched GUI-only execution across eight models including GPT-6 Astra and Claude Opus 5. A notable finding: Qwen3.8-Max uses 19.4× more reasoning tokens than GPT-6 Astra on real macOS tasks, underscoring that raw benchmark scores can obscure huge efficiency differences.

### MadsLorentzen/ai-job-search — AI job application framework built on Claude Code
**2213 stars/day** · ⭐ 51,392 total · [Repo](https://github.com/MadsLorentzen/ai-job-search)

A fork-and-own Python framework that uses Claude Code to automate the full job-hunting loop: scrape postings, evaluate fit, tailor CVs, write cover letters, and prep for interviews — all locally. The author (a geophysicist who lost his job in late 2025) built and used this himself: 69 tailored applications, 20 first interviews, one signed offer. ## 📡 Analysis

### How the Claude Code team does code review (quoted by Simon Willison)
*2026-10-16* · [Post](https://simonwillison.net/2026/Oct/16/code-review/) · tags: `anthropic`, `claude`, `claude-code`, `code-review`, `coding-agents`, `agentic-engineering`

Addy Osmani, Morgan Westlee Lunt, and Qing Wang from Anthropic describe a shift away from "did a human read the code?" as the quality gate. Instead, Claude Code reviews changes continuously as they're written — more like spellcheck than a PR gate — so most routine errors are caught and fixed before a human ever sees them. This reframes human review as reserved for higher-level judgment, which has direct implications for how engineering teams should think about agentic tooling in their own CI/CD pipelines.
