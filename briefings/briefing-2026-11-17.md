### Sage S2.1 Flash Technical Report
**81 upvotes** · Kun Cai et al. · [Paper](https://huggingface.co/papers/2611.21072)

Sage S1.5 Flash is a 320B-parameter mixture-of-experts model built for scientific reasoning and agentic tasks, with dedicated encoders for molecular graphs, biological sequences, and spectra. It was evaluated on 33 benchmarks across 7 domains, ranking first on OfficeQA Pro (72.2), MLE-bench Lite (90.3 HumanRank), and SpreadsheetBench 2. Its particular strength is in documentary evidence handling and verifiable machine learning tasks, with competitive performance on desktop/browser automation (OSWorld-Verified: 85.2). A strong contender for teams exploring science-domain LLM agents.

### AllocFlow: End-to-End Portfolio Trading Action Generation from Raw Market Data
**65 upvotes** · Annan Wang et al. · [Paper](https://huggingface.co/papers/2611.19937)

AllocFlow is a flow-matching framework that generates joint portfolio allocations directly from raw multi-asset market data, bypassing the classic decoupled signal/portfolio-construction pipeline. It uses a cross-asset Transformer and a two-stage training scheme: imitation learning first, then group-relative RL refinement. RL refinement boosted annualized net return from 27.79% to 51.38% and the Calmar ratio from 0.955 to 4.043 on hourly crypto futures, reaching a Calmar ratio of 4.90 on 6 months of unseen 2026 data without retraining. Relevant for quant and FinML engineers looking to unify forecasting and execution.

### InclusionMed: Benchmarking AI for Inclusive Healthcare
**60 upvotes** · The InclusionMed Collaboration · [Paper](https://huggingface.co/papers/2611.21218)

InclusionMed is an open evaluation initiative that benchmarks medical AI across healthcare roles (e.g., patient vs. clinician) and AI capabilities (e.g., clinical decision-making vs. patient communication). The first release includes 5 benchmarks selected from 388 candidates; frontier LLMs scored between 17.5 and 49.1 out of 100 on the InclusionMed Index. Notably, all top-10 models scored higher on patient communication than on clinical decision-making, and models with similar overall scores showed large differences in inference cost. A timely push for more context-sensitive, role-aware evaluation of medical AI.

## 🛠 Tools

### obra/superpowers — Agentic skills framework for coding agents
**1905 stars/day** · [Repo](https://github.com/obra/superpowers)

Superpowers is a Shell-based methodology and composable skills framework (~319k total stars) designed to make coding agents more reliable — it enforces spec-first, TDD, YAGNI, and DRY patterns before writing a single line of code. It supports 15+ coding agents out of the box (Claude Code, Codex, Cursor, Devin, Gemini CLI, Grok Build, Qwen Code, etc.) via a subagent-driven-development workflow. The agent decomposes tasks into reviewable chunks, spawns subagents per task, and inspects results — aiming to prevent the "junior dev with no judgment" failure mode. Useful drop-in scaffolding for teams building on any major agentic coding tool.

### dream-num/univer — Open-source AI office SDK
**1776 stars/day** · [Repo](https://github.com/dream-num/univer)

Univer is a TypeScript SDK for embedding spreadsheet, document, and presentation editing capabilities — with AI agent support — directly into your own product. It covers editing, calculation, real-time collaboration, and file processing, built on an extensible open-source core. Positioned as a self-hostable alternative for teams that want Office-like functionality with native AI agent integration, without depending on SaaS providers. Relevant if you're building AI-augmented productivity tooling or document-heavy workflows.

### ag-ui-protocol/ag-ui — Open protocol for connecting AI agents to frontend apps
**1444 stars/day** · [Repo](https://github.com/ag-ui-protocol/ag-ui)

AG-UI is a lightweight, event-based open protocol (MIT license, ~19.9k stars, actively updated today) that standardizes the bidirectional connection between AI agents and user-facing web apps. It addresses the fundamental mismatch between agents (streaming tokens, tool calls, subagents, human-in-the-loop pauses) and the classic request/response model. Available on both npm (`@ag-ui/core`) and PyPI (`ag-ui-protocol`), it's framework-agnostic and aims to be the "HTTP of agent-UI integration." Engineers building chat interfaces or copilot UIs on top of any agent framework should take note.

## 📡 Analysis

### llm 0.37.3
*2026-11-16* · [Post](https://simonwillison.net/2026/Nov/16/llm/) · tags: `llm`, `sqlite`, `generative-ai`, `llms`, `d-richard-hipp`

Patch release for Simon's CLI LLM tool, triggered by a breaking change in SQLite 3.54.1 (shipped via Homebrew) that changed how `json_object` serializes nested JSON arrays — returning a string instead of a JSON value. The fix wraps the inner query with an explicit `json()` call, following a clarification from SQLite's author D. Richard Hipp that 3.54.0 behavior was actually the bug. Worth checking if you use LLM via Homebrew and have been seeing logging failures.

### datasette-maplibre 0.1a0
*2026-11-15* · [Post](https://simonwillison.net/2026/Nov/15/datasette-maplibre/) · tags: `visualization`, `geospatial`, `datasette`, `datasette-lite`, `openstreetmap`, `claude-mythos-fable`

New Datasette plugin combining MapLibre GL with OpenFreeMap (a free vector map server) for rendering geospatial data — supporting both GeoJSON shapes and lat/lon points on the same map. Notably, most of it was built from a single prompt to Claude Fable 5.2, which also came up with the idea of lazy-loading WebGL previews when shapes scroll into view. Works in-browser via Datasette Lite and Pyodide/WebAssembly — a solid example of LLM-assisted plugin development producing genuinely usable results.
