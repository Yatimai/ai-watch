## 🔬 Research

### VoxMem: Benchmarking Multimodal Memory in Large Audio Language Models
**113 upvotes** · Yang Xiao, Vidhyasaharan Sethu, Eun-Jung Holden, Ting Dang · [Paper](https://huggingface.co/papers/2609.32607)

Current benchmarks for spoken dialogue systems only measure whether models remember *what* was said, ignoring *who* said it, *how* it was said, and ambient sounds — information that exists only in the audio signal. VoxMem fixes this with 3,196 evaluation instances across 34,743 spoken sessions (177 hours), combining four acoustic evidence types with four memory operations over multi-session histories up to 64K tokens. Evaluating 15 large audio-language models, none exceeded 40% accuracy at 32K context — a clear indication that audio memory is a wide-open research problem.

### Omni-IO Skills: Harnessing Your Agent Omni-Native
**105 upvotes** · Yanlin Li, Mingyang Hao, Shengqiong Wu, Hao Fei, Mong-Li Lee · [Paper](https://huggingface.co/papers/2609.31847)

Instead of retraining a foundation model to handle new modalities, Omni-IO Skills is a plug-and-play "Agent Harness" that wraps existing agents with 27 modular Skills covering text, image, audio, video, 3D assets, documents, and code. Multi-asset workflows are expressed as Declarative Execution Graphs that schedule operations concurrently and cache outputs across turns. On the UniM-90 benchmark, wrapping GPT-5.6 Sol raised its Semantic–Quality Coupled Score from 26.99 to 74.94 and bumped input-support rate from 40% to 100% — with no change to the underlying reasoning model.

### PanoVLN: Towards Effective Panoramic Vision-and-Language Navigation
**105 upvotes** · Zhen Wang, Changpeng Wang, Zhe Liu, Zhangyang Qi, Yuxiang Lu · [Paper](https://huggingface.co/papers/2609.34759)

PanoVLN replaces the perspective-camera assumption in Vision-and-Language Navigation with full 360° panoramic observations, enabling agents to spot corridors and branching points outside a narrow field of view. Three coordinated changes are required to unlock that advantage: longer action sequence prediction with confidence-guided re-planning, training routes rich in branching points, and combined semantic + geometric features to capture spatial layout without extra visual tokens. With a 4B backbone and RGB-only input, PanoVLN beats the previous SOTA by +11.9% and +8.7% success rate on R2R-CE and RxR-CE Val-Unseen, and transfers to a real quadruped robot.

## 🛠 Tools

### debpalash/VoiceStudio — Fully-local ElevenLabs alternative
**3,481 stars/day** · 49,805 total stars · Python · [Repo](https://github.com/debpalash/VoiceStudio)

VoiceStudio is an Electron desktop app (AGPL-3.0) offering voice cloning, voice design, video dubbing, dictation, transcription and audiobook generation across 646 languages, all running locally without a cloud subscription. It is powered by k2-fsa/OmniVoice by default but supports swappable engine backends, a local API, and MCP integration for agent workflows. For teams wanting ElevenLabs-grade features without data leaving their machines, this is the most complete open-source option currently available.

### NVIDIA/OpenShell — Secure sandbox runtime for autonomous AI agents
**1,280 stars/day** · 11,398 total stars · Rust · [Repo](https://github.com/NVIDIA/OpenShell)

OpenShell (Apache 2.0) is a Rust-based kernel-level sandbox that lets AI agents read files, install packages, call APIs, and use credentials while enforcing per-agent policies on every syscall and network connection. It adds formal verification to pre-validate what a policy change would allow before it is applied — a meaningful step beyond typical container-based isolation. Given the rise of multi-agent pipelines that need real OS access, a GPU-vendor-backed, open-source enforcement layer fills a genuine security gap.

### VectifyAI/PageIndex — Vectorless, reasoning-based RAG
**1,095 stars/day** · 37,847 total stars · Python · [Repo](https://github.com/VectifyAI/PageIndex)

PageIndex discards the classic vector-DB + chunking pipeline: instead, it builds a tree index over documents and uses LLM reasoning to navigate and retrieve context, mimicking how a human reads a report. The August 2026 SDK release added a fully local mode (`pip install pageindex`) and "PageIndex Flash" for fast tree indexing of text-based PDFs. For long professional documents where chunking destroys cross-page context, this reasoning-first approach is worth evaluating as a drop-in RAG alternative.

### Anthropic Frontier Red Team: GLM-5.3 and advanced cyber capabilities
*2026-09-29* · [Post](https://simonwillison.net/2026/Sep/29/anthropic-frontier-red-team/) · tags: anthropic, ai-security-research, glm, ai-in-china, llms

Anthropic's Frontier Red Team found that GLM-5.3 (a Chinese-developed model) succeeds at full control-flow hijack exploits in 4% of binary exploitation benchmark trials, while Claude Mythos Preview reaches 6% — up from 0% for both Claude Opus 4.6 and GLM-5.2. The key concern is not the absolute percentage but that a meaningful capability threshold has been crossed simultaneously by models from different organisations. This is an early signal that autonomous binary exploitation is transitioning from a frontier capability to a more broadly accessible one.
