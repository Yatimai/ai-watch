## 🔬 Research

### From Traces to Agentic Worlds: Agentic Language World Models for Interactive Environment Simulation
**164 upvotes** · Quanyu Long et al. · [Paper](https://huggingface.co/papers/2610.06100)

When you can't rebuild an environment from scratch, you can simulate it from its logs. **Trace2Env** is a learning-free framework that converts historical interaction traces into a structured "worldbook" (schemas, grounded evidence, behavioral rules) that a world-model agent uses to faithfully simulate that environment at runtime. Tested across nine environments, it outperforms standard prompt-based LWMs on both next-observation fidelity and long-horizon consistency, and actions generated against it stay valid more often when replayed in the real system. This is directly useful for agent training/evaluation when the original API or simulator is unavailable or too expensive to run.

### Learn2Play Bench: How Well Do LLM Agents Learn from Experience in Unfamiliar Environments?
**117 upvotes** · Yibo Li et al. · [Paper](https://huggingface.co/papers/2610.08215)

Most agent benchmarks test reasoning on known rules — **Learn2Play Bench** closes that loophole with novel, counterintuitive text games whose rules can only be discovered through play. Key findings: retaining raw action/feedback logs beats summarising them into rules; top human players still outscores all evaluated agents by exploring more diverse strategies; and swapping the agent *harness* (not the backbone model) can meaningfully lift performance while cutting inference cost. A clean diagnostic for separating genuine in-context learning from memorised knowledge.

### TokenRouter: Efficient Serving System for Token-Level LLM Routing
**91 upvotes** · Tianyu Fu et al. · [Paper](https://huggingface.co/papers/2610.12242) · [Code](https://github.com/thu-nics/TokenRouter)

Token-level routing (selecting different models per token rather than per query) can push the cost-quality frontier further than session-level routing, but existing serving stacks break under it due to step desynchronisation and batch-admission delays. **TokenRouter** introduces a request-centric programming model backed by per-model async subservers and a mathematically-derived delayed-batching scheduler, delivering **2× to 64× higher decoding throughput** than existing systems across diverse workloads. Practically relevant for any team running heterogeneous model fleets in production.

## 🛠 Tools

### morluto/rea — Reverse-engineer anything with agents, down to native binaries
**15,335 stars/day** · 37k total stars · [Repo](https://github.com/morluto/rea)

REA is a TypeScript MCP (Model Context Protocol) server that exposes a unified tool catalog for reverse-engineering — covering app behavior, runtime traces, and native binaries — to any MCP-compatible AI agent. With 37k stars and active multilingual docs (15 languages), it has clearly found a large audience among security researchers and platform engineers. The MIT-licensed npm package `rea-agents` can be wired into Claude, Codex, or any MCP host in minutes.

### cathrynlavery/diagram-design — Editorial diagram system for AI coding agents
**1,744 stars/day** · 47k total stars · [Repo](https://github.com/cathrynlavery/diagram-design)

A collection of 42 diagram types delivered as self-contained HTML + SVG files, designed to be consumed as agent skills by Claude Code, Codex, Copilot, and others. The philosophy is strict editorial aesthetics — no shadows, no generic boxes, no Mermaid — with semantic layout grammars that separate behavior from presentation (queues, trust boundaries, Wardley maps, UML, etc.). v2.5.10 added ten new layout types; it can also redraw existing draw.io or Excalidraw sources. At 47k stars, it is the go-to diagram layer for teams running AI-assisted technical writing.

### mattpocock/skills — Composable agent skills for real engineering workflows
**1,696 stars/day** · 282k total stars · [Repo](https://github.com/mattpocock/skills)

Matt Pocock (Total TypeScript) publishes the agent skill files from his own `.agents/` directory as small, composable Shell/Markdown units installable via `claude plugin install` or `codex plugin add`. With 282k stars and ~60k newsletter subscribers, this is one of the most widely-adopted skill registries in the ecosystem.

### ttok 1.0
*2026-10-09* · [Post](https://simonwillison.net/2026/Oct/9/ttok/) · tags: `tokenization`, `openai`, `llms`

Simon's CLI token-counter `ttok` (built on OpenAI's `tiktoken`) reaches 1.0 with a switch of the default tokenizer from GPT-4 to the GPT-5/GPT-6 family. The change was prompted by community research confirming that all seven GPT-5/6 variants share the same tokenizer and produce identical token counts. A minor but practically relevant update for anyone using `ttok` in CI pipelines or prompt budgeting scripts.
