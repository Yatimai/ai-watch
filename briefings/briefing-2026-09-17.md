## 🔬 Research

### Continual Learning Mechanisms Compose for Long-Horizon Memorization
**292 upvotes** · Zheyuan Zhang, Alvin Zhang, Daniel Khashabi, Tianmin Shu · [Paper](https://huggingface.co/papers/2609.06986)

This paper tackles a fundamental LLM limitation: catastrophic forgetting during sequential fine-tuning. The authors test 100-task memorization benchmarks and show that naive sequential fine-tuning retains only 1.2% of earlier knowledge, while combining complementary mechanisms (data anchors + function anchors + weight anchors + merged LoRA) pushes retention to 34.9% — a 28× improvement. The key insight is that no single continual learning mechanism is sufficient at this horizon; the gains come from composing mechanisms that target different *sources* of forgetting. Practically relevant for any team trying to incrementally update a deployed model without retraining from scratch.

### AI for Games in the Foundation Model Era
**113 upvotes** · Meng Luo, Yanlin Li et al. · [Paper](https://huggingface.co/papers/2609.16679)

A comprehensive survey organizing the literature on foundation models in game AI into six roles: playing, player/game modeling, design, development, runtime adaptation, and testing. The paper highlights meaningful cross-role connections (e.g., gameplay trajectories training world models, learned environments supplying agent experience) while being clear-eyed about what doesn't transfer: control schemes, engine interfaces, and player contexts remain largely game-specific. Useful as a map of the space, and as a caution against overgeneralizing benchmark results across game settings.

### StepAudio 3 Realtime Technical Report
**101 upvotes** · Bin Lin, Bo Zhao et al. · [Paper](https://huggingface.co/papers/2609.14005)

StepAudio 3 Realtime is an audio-language model designed for low-latency spoken interaction, built around a listen-converse-think-act loop with full-duplex handling of pauses, backchannels, and interruptions. Its standout feature is **Think-While-Speaking**: the model runs private chain-of-thought reasoning *in parallel* with speech output, resolving the usual tradeoff between latency and deliberation. Benchmark results are strong: 90.6 on MMSU, 98.9 on Artificial Analysis Full-Duplex Bench, and 56% task-success on τ-Voice — making it a credible contender for real-time voice agent deployments.

## 🛠 Tools

### cloudflare/security-audit-skill — Multi-phase AI security auditing skill
**3,606 stars/day** · [Repo](https://github.com/cloudflare/security-audit-skill)

This is the single-repo starting point that seeded Cloudflare's own fleet-wide vulnerability discovery harness. It orchestrates isolated agents through six structured phases — reconnaissance, coverage-led hunting, candidate validation, structured output, independent record verification, and target-neutral reporting — producing machine-readable `findings.json` with clearly separated `confirmed`, `needs_validation`, and `rejected` verdicts. Multiple runs are additive, making it suitable for continuous auditing. At 9,174 total stars, it's already attracting significant adoption from teams wanting an auditable, agent-driven security workflow.

### alibaba/open-code-review — Production-scale hybrid code review tool
**3,290 stars/day** · [Repo](https://github.com/alibaba/open-code-review)

Built and battle-tested at Alibaba's scale, this Go-based tool combines deterministic rule pipelines with an LLM agent for line-level PR comments, covering NPE, thread safety, XSS, and SQL injection across multiple languages. It's compatible with both OpenAI and Anthropic APIs, and already has 33,622 stars with active commits as of today. For teams that want LLM-augmented code review without giving up precision and speed, this is a more production-ready option than most.

### Tencent/BrowserSkill — Let AI agents use your logged-in browser without interrupting you
**1,350 stars/day** · [Repo](https://github.com/Tencent/BrowserSkill)

BrowserSkill connects agents (Cursor, Claude Code, Codex, and others) to the user's *already authenticated* browser via a CLI daemon and a Chrome/Edge extension, so agents can act on real sessions without needing separate test accounts. Browser tasks run in a dedicated Agent Window to avoid disrupting the user's active tabs, and a built-in human-in-the-loop mechanism lets the agent hand off to the user for captchas or confirmations before resuming. At 3,622 stars and last pushed today, it fills a real gap for agents that need to interact with authenticated web surfaces.
