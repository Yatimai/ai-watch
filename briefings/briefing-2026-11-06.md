## 🔬 Research

### Turns Matter: Advancing Streaming Video RL via Turn-Level Credit
**126 upvotes** · Shuai Dong et al. · [Paper](https://huggingface.co/papers/2611.06728)

Current RL approaches for streaming video understanding (where a model must decide turn-by-turn whether to respond or keep watching) apply a single trajectory-level advantage across all turns — which can reward redundant replies and penalize useful ones. **TurnWise** fixes this with turn-level credit assignment via silence-completed prefix scoring, plus a turn-mean policy optimization that weights response and silence decisions equally regardless of output length. The result is better streaming policy learning without a learned critic or extra rollouts. Directly relevant for anyone building real-time video agents with GRPO-based training.

### Decoupled Predictive Decision Making: A Shared Conditional Predictor for Agents
**113 upvotes** · Lang Mo et al. · [Paper](https://huggingface.co/papers/2611.02075)

**DPDM** separates agent decision-making into two frozen components: an LLM for semantic representations (Qwen3.5-27B tested) and a shared pretrained predictor (LimiX-2) that handles all task types — tool selection, candidate ranking, reasoning assessment — purely via in-context evidence at inference time, with no parameter updates. This yields a +6.1pp mean accuracy jump across 50 benchmarks (78.80% → 84.92%) and massive gains on tool-use tasks (+34.26% on BFCL, +28.87% on ToolSandbox). The key insight: empirical inference from deployment history is an independently improvable capability that doesn't require retraining the LLM.

### VFlash: Fast, Accurate Visual Planning via Flash Primitive Decoding
**67 upvotes** · Yu-Cheng Chou et al. · [Paper](https://huggingface.co/papers/2611.08449)

Autoregressive VLMs generate visual plans (points, boxes, trajectories) one coordinate token at a time — expensive for robotics and autonomous driving. **VFlash** introduces a lightweight drafter that predicts an entire visual primitive (box, trajectory, etc.) in a single forward pass, bypassing the need to match the autoregressive token sequence exactly. This delivers ~25× faster generation for 3D point motion forecasting, reduces trajectory prediction errors, and boosts success rate from 62.6% to 70.2% on MolmoSpaces task suites. A practical speedup for anyone deploying VLMs in physical AI pipelines.

## 🛠 Tools

### cloudflare/security-audit-skill — Multi-phase agentic security auditing
**2524 stars/day** · [Repo](https://github.com/cloudflare/security-audit-skill)

This is the coding-agent skill that seeded Cloudflare's internal vulnerability discovery harness, now open-sourced. It orchestrates isolated sub-agents through six structured phases: reconnaissance, coverage-led hunting, candidate validation, structured output (findings.json), independent record verification, and target-neutral reporting. Findings are machine-readable and triaged into `confirmed`, `needs_validation`, and `rejected`. Multiple runs against the same repo are additive — a production-grade starting point for anyone building automated security tooling on top of coding agents.

### NVIDIA/auto-ontology — Graph-based semantic reasoning layer for LLM/agent workflows
**2005 stars/day** · [Repo](https://github.com/NVIDIA/auto-ontology)

NVIDIA's Auto Ontology builds enterprise knowledge graphs from metadata and exposes them to agents via MCP, CLI, and API — giving LLMs a trusted, validated semantic layer for metrics, entities, and relationships instead of relying on raw retrieval. It supports deterministic query generation with provenance, reconciles conflicting definitions across data systems, and can fold certified corrections back into the ontology over time. Fresh push today (2026-11-06) and Apache 2.0 licensed, though external contributions are not yet accepted.
