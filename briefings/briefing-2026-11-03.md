### Wave Forcing: Towards Speed-of-Light Streaming Video Generation
**94 upvotes** · Yijie Jin et al. · [Paper](https://huggingface.co/papers/2611.00859)

Wave Forcing (WF) proposes a co-designed generation, training, and execution framework for real-time continuous video output using multi-step diffusion. By introducing chunk-wise causal attention and staggered pipeline stages across model replicas, it achieves a 1F1C schedule (one output chunk per forward round after fill). Tested on Wan2.1-T2V-1.3B on 8× H200 GPUs, 4-step WF delivers 134.8 end-to-end FPS — 7× single-GPU throughput — and its Wave Parallelism strategy yields up to 2.53× the throughput of Ulysses/Ring context-parallel baselines across 1.3B–14B model scales. This is a significant step toward truly real-time long-video generation at production scale.

### CoworkOS: Scaling Agent Coworkers for Real-world Automation
**83 upvotes** · Jiajie Jin et al. · [Paper](https://huggingface.co/papers/2611.03178)

CoworkOS is a general-purpose framework for long-horizon AI-driven productivity work, separating task strategy (model decisions) from execution management (runtime state). Its three-layer architecture supports delegation to synchronous or asynchronous subagents, a shared application layer enabling human-in-the-loop edits on live documents/CAD/Blender scenes, and persistent hierarchical semantic memory across sessions. Competitive against Codex and DeepSeek Harness on 12 benchmarks, it also demonstrates self-improvement: using GLM-5.3 as backbone and RSI-driven post-training on Qwen3.6-35B-A3B, average scores across 8 benchmarks rose from 33.19 to 42.95 (+9.76) over five rounds. The human-editable shared workspace design is an interesting architectural choice for practical agentic deployment.

### CUA-Master: Scaling Computer-use Agents through Open-World Recursive Improvements
**69 upvotes** · Xinlei Yu et al. · [Paper](https://huggingface.co/papers/2611.03126)

CUA-Master introduces a nested double-loop recursive improvement framework for Computer Use Agents (CUAs): an outer loop drives world-data-model co-evolution, while an inner loop combines open-world workflow mining (from instructional videos) with autocatalytic task synthesis. A snapshot-rollback retry mechanism improves trajectory collection reliability in real GUI environments. CUA-Master-27B achieves 80.2 on OSWorld Verified, 36.9 on OSWorld 2.0, 43.9 on WeaveBench, and 25.0 on Agents' Last Exam — competitive results that demonstrate the value of iterative, diversity-driven data pipelines over pure self-play.

## 🛠 Tools

### vercel-labs/agent-desktop — Computer use CLI for AI agents
**3 792 stars/day** · [Repo](https://github.com/vercel-labs/agent-desktop)

A cross-platform CLI (macOS, Windows, Linux) and C library, written in Rust, that exposes the OS accessibility tree as structured JSON so AI agents can read and control desktop apps without pixel matching. Each CLI call is a standalone process that returns refs to all actionable UI elements; the agent acts on a ref, snapshots again, and loops. Installable via `npm install -g agent-desktop`, with 11 844 total stars already — Vercel Labs is clearly positioning this as infrastructure for the emerging computer-use agent ecosystem.

### I discovered a sound that leaks your exact location (and it's everywhere)
2026-11-03 · [Post](https://simonwillison.net/2026/Nov/3/a-sound-that-leaks-your-exact-location/) · tags: `privacy`, `youtube`

Simon highlights an OSINT technique by Colsto: by extracting barely-audible aircraft background noise from a video's audio track, modeling each plane's Doppler curve, and cross-referencing against ADS-B flight data, one can triangulate the video's exact recording location. The method requires no visual information, making it effective against intentionally anonymized footage. A sobering reminder that passive environmental signals in media can carry significant location fingerprints — relevant for anyone building or auditing AI systems that process user-uploaded video.

### llm 0.37
2026-11-02 · [Post](https://simonwillison.net/2026/Nov/2/llm/) · tags: `open-source`, `ai`, `llms`, `embeddings`, `llm`

Simon's `llm` CLI tool and Python library received a large two-month update: new models (`gpt-6.1-sol`, `gpt-6.1-terra`), a new `llm openai endpoint add` command for OpenAI-compatible endpoints, and a default model switch to `gpt-6-luna` (half the price of the previous default `gpt-5.6-luna`).
