## 🔬 Research

### Training Object Permanence in World Models
**128 upvotes** · Zhang et al. · [Paper](https://huggingface.co/papers/2609.28654)

The authors introduce WROP, a 1.5M-sample dataset of 150 cognitive-science-inspired tasks (built with Blender) to test and train object permanence in video generation models. They evaluate 14 video models and find that their 16B model PWM-WROP ranks first among continuation models in blind Elo scoring. This matters because object permanence is a foundational cognitive primitive — without it, "world models" remain glorified texture generators, not genuine physical reasoners. All data, weights, and the native-PyTorch training stack (targeting AWS Trainium2) are released openly.

### SpeakerMem-R1: Speaker-Centered Dual-Track Memory for Multi-Party Dialogue
**82 upvotes** · Zheng et al. · [Paper](https://huggingface.co/papers/2609.26780)

SpeakerMem-R1 tackles a concrete failure mode of LLM memory systems in group chats: losing track of *who* said *what* and *about whom*. Its dual-track architecture stores verbatim speaker-labeled messages alongside derived relational states at both person and group level, queried by entity/event/time. On the EverMemBench public leaderboard it achieves 62.33%, the best reported result, and RL training (GRPO with a custom SpeakerLevenshtein reward) raises Writer accuracy from 57.38% to 68.20% over SFT alone. Relevant as multi-agent and team-assistant deployments make multi-party memory a production-grade requirement.

### Spatial-Interactor: Learning Spatial Reasoning through Interaction with the Observable Physical World
**45 upvotes** · Yao et al. · [Paper](https://huggingface.co/papers/2609.23038)

Spatial-Interactor trains VLMs to reason about 3D space by learning from *interaction trajectories* (action → observation pairs) rather than static image-question datasets. The framework uses a three-level curriculum (passive transitions → active self-motion → long-horizon trajectories) and a 108K-sample dataset (LSI-108K) mixing simulated and real data. On-Policy Distillation with a privileged teacher lets the student model chain consecutive state transitions coherently. This is a credible step toward embodied agents that can track "where things are" after they move or the camera shifts.

## 🛠 Tools

### paperclipai/paperclip — Open-source agent team management platform
**1853 stars/day** · ⭐ 83,470 total · [Repo](https://github.com/paperclipai/paperclip)

Paperclip is a Node.js + React dashboard for orchestrating *teams* of AI agents toward business goals — think org charts, budgets, goal assignment, and cost tracking in one UI. The tagline: "If your agent is an employee, Paperclip is the company." MIT-licensed and self-hostable, it targets teams wanting governance and oversight over multiple agents rather than just a single-agent runner. The explosive star count (83K total) suggests it has struck a nerve as agent deployments scale beyond hobby projects.

---

### vectorize-io/hindsight — Agent memory that learns, not just remembers
**1652 stars/day** · ⭐ 28,585 total · [Repo](https://github.com/vectorize-io/hindsight)

Hindsight is a Python library (also available via NPM) that gives agents a memory system designed to improve behaviour over time, rather than simply replaying conversation history. It ships with benchmarks, a cookbook, integrations, and a managed cloud option. The distinction from naive RAG-based memory is the emphasis on *learning* — extracting generalizable patterns from past interactions. MIT-licensed; a companion arXiv paper (2512.12818) backs the approach.

---

### google/ax — Kubernetes-style declarative orchestration for agent workloads
**1386 stars/day** · ⭐ 11,090 total · [Repo](https://github.com/google/ax)

Written in Go, `ax` treats agents as a new class of workload (neither stateless services nor batch jobs) and provides three YAML-declared primitives: `Task` (sandboxed agent execution), `Workspace` (pre-wired Git repos, MCP servers, skills), and `Model` (LLM config). If you've used `kubectl`, the CLI (`ax apply`, `ax watch`, `ax ssh`) will feel immediately familiar. Still pre-stable with expected breaking changes, but Google backing and a Kubernetes-inspired mental model make this one to watch for teams running agents at cluster scale.
