## 🔬 Research

### SO-Arena: Benchmarking the Capability Spectrum and Reliability of System One Models
**67 upvotes** · Lichen Li et al. (NUS) · [Paper](https://huggingface.co/papers/2611.15777)

SO-Arena is a benchmark evaluating "System One" models — fast, non-chain-of-thought decision-makers — across 11 domains and 5 capability families, testing 21 models. Beyond accuracy, it specifically measures *decision reliability*: stability under option-set perturbations and correct abstention when no valid answer exists. The key finding is a dissociation between performance and reliability: the top-scoring model overall ranks only 7th on reliability, a warning sign for anyone deploying these models in production decision pipelines.

### Scaling Mathematical Proof Supervision from Structured Textbooks
**44 upvotes** · Youqing Fang et al. · [Paper](https://huggingface.co/papers/2610.40394)

TOME-Math converts 2,118 university-level math textbooks into ~380K structured proof-supervision records, preserving chapter order, proposition-proof links, and dependency graphs — information typically discarded when flattening data into plain QA pairs. Fine-tuning on this corpus improves unweighted mean score by **16.7 percentage points** over the base model and beats all three public instruction-data baselines. The corpus will be released publicly, making it a potentially significant resource for researchers working on mathematical reasoning.

### BirdDreams: Joint Perspective and BEV Video Generation for a Plausible, Reactive Driving World Model
**42 upvotes** · Junyoung Seo et al. · [Paper](https://huggingface.co/papers/2611.14815)

BirdDreams is an autoregressive driving world model that simultaneously generates first-person perspective video and a bird's-eye-view (BEV) schematic video, using cross-attention between two video diffusion transformers. By making the BEV part of the *predicted* output (rather than a required input), the model eliminates the need for HD maps or future vehicle trajectories at inference time — a significant practical constraint for prior work. At test time on PhysicalAI-AV and nuScenes, it outperforms perspective-only baselines in ego-trajectory fidelity and surrounding-vehicle realism, as confirmed by human evaluation.

## 🛠 Tools

### GoogleChrome/modern-web-guidance-src — Embed modern web best practices into coding agents
**1,875 stars/day** · [Repo](https://github.com/GoogleChrome/modern-web-guidance-src)

This is the source repo for **Modern Web Guidance**, a set of "skills" that inject up-to-date web platform knowledge and browser compatibility data directly into coding agents (e.g. Cursor, Claude, Copilot). It steers agents away from legacy patterns toward modern APIs, and is co-stewarded by Chrome, Edge, Firefox, and MDN teams — giving it unusually broad browser-vendor backing. Install via `npx modern-web-guidance@latest install`; it also includes a codebase scanner to flag legacy patterns for modernisation.

## 📡 Analysis

### llm-gemini 0.37 — Gemini 4 Hydrogen lands as Google's new budget and free-tier model
2026-11-12 · [Post](https://simonwillison.net/2026/Nov/12/llm-gemini/) · tags: `gemini`, `llm`, `llm-pricing`, `google`

Google released **Gemini 4 Hydrogen**, the cheapest member of the Gemini 4 family, priced at $1.50/$7.50 per million input/output tokens — currently only a 25% discount versus Carbon and Argon, but effectively a 75% discount after their December 1st price doubling. Willison notes it's still ~15× more expensive than Claude Haiku 5.5 and GPT-6 Luna ($0.10/$0.50), and that Hydrogen's visual quality noticeably lags its siblings despite similar pricing today. Hydrogen is now Google's free-tier model and will power AI features in Google Search.

### Gemini Decisions API — Google enters the structured decision-model market
2026-11-11 · [Post](https://simonwillison.net/2026/Nov/11/gemini-decisions-api/) · tags: `gemini`, `decision-models`, `llm-release`

Google launched **Gemini Decision 1**, a dedicated API for yes/no, choice, and rubric-scoring questions — joining Jev and OpenAI's decision model in what is now a three-player category. At $0.10/M input tokens (output free), it matches OpenAI's price but is 2.4× more expensive than Jev ($0.042/M). Its key differentiator is multimodality: unlike Jev (text/JSON only) and OpenAI (text + images), Gemini Decision 1 handles text, images, audio, video, and PDFs — the first decision API capable of reasoning over video content.

### aws-emulator — AWS releases an official local emulator for all its services
2026-11-11 · [Post](https://simonwillison.net/2026/Nov/11/aws-emulator/) · tags: `amazon-web-services`, `testing`, `rust`, `agentic-engineering`

AWS finally ships an official local emulator so developers can run tests against AWS services without a paid API key or live cloud environment — a long-standing pain point in AWS-based development. It's written in Rust and accumulated **29,684 commits in its first three weeks**, built by a large swarm of AI agents. Currently Docker is required on macOS and Windows, which limits standalone portability, but it represents a major step forward for local AWS testing workflows.
