## 🔬 Research

### Scaling Automatic Research Agents via World Models (WMRL)
**433 upvotes** · Xiyuan Yang et al. · [Paper](https://huggingface.co/papers/2608.12564)

The key bottleneck in applying RL to autonomous research agents isn't compute — it's environment execution: each trajectory needs its own sandbox and real wall-clock time, which can't be batched. WMRL replaces live environment execution with a learned world model, adding Online Debiasing and Inverse-Variance Denoising to correct for model imperfections. The result is a 3–4× training speedup, and post-trained 4B/9B agents that outperform open-weight models of 48B and 120B on held-out benchmarks. The technique generalizes beyond AutoResearch to embodied VLA policies, suggesting it's a broadly applicable RL scaling primitive.

### Show-Harness: Just a VLM Agent Can Play Robots
**134 upvotes** · Yanzhe Chen et al. · [Paper](https://huggingface.co/papers/2609.10522)

Show-Harness is a thin semantic interface layer that lets any VLM — including closed-source frontier models — control robots without embodiment-specific pretraining. The key idea: expose discrete semantic action units the VLM reasons over naturally, then use deterministic per-embodiment interpreters to ground them into physical actions. The companion GUMI interface also allows humans and agents to collect robot demonstrations via GUI, eliminating the need for specialized teleoperation hardware. This could meaningfully lower the barrier to deploying off-the-shelf VLMs (e.g., GPT-4o, Claude) on physical robots at low cost.

### NCP-ArchPreview: Latent Space Language Models via Next Concept Prediction
**107 upvotes** · NCP Team · [Paper](https://huggingface.co/papers/2609.10715)

NCP-ArchPreview augments standard next-token prediction with a "Next Concept Prediction" objective: the model learns to predict multi-token discrete concepts built from its own hidden states, using a product-quantized vocabulary. At 8.9B parameters trained on 5.73T tokens (Dolma-3), it matches OLMo-3-7B's final training loss using only 51.3% of the tokens, and beats it by 2.45 points on downstream benchmarks (+5.99 on GSM8K). The 17M-parameter VQ module also doubles as a lightweight domain-adaptation interface, and injecting concept representations into speculative decoding improves accepted token length by 4.17% — a practical win for inference efficiency.

## 🛠 Tools

### ayghri/i-have-adhd — Make your coding agent lead with the answer
**3 882 stars/day** · [Repo](https://github.com/ayghri/i-have-adhd)

A drop-in skill/plugin (installable via a single prompt) that rewires coding agents to put the actionable answer first — numbered steps, no filler, no "Hope this helps!" It works with any agent that supports AGENTS.md-style skill injection and requires zero code changes to your project. At ~40K total stars after a surge day, it has clearly resonated: verbosity and burying of answers are among the top complaints about AI coding assistants.

### obra/superpowers — Full software development methodology for coding agents
**732 stars/day** · [Repo](https://github.com/obra/superpowers)

Superpowers is a composable skills framework (285K total stars) compatible with Claude Code, Cursor, Codex, Devin, Gemini CLI, Grok, and a dozen others. It imposes a structured workflow on agents: spec negotiation → implementation plan → subagent-driven TDD execution — with the explicit goal of keeping autonomous agent runs going for hours without human intervention. The emphasis on red/green TDD, YAGNI, and DRY makes it opinionated by design, positioning it as a full engineering discipline rather than just a prompt collection.

### vastsa/PI-Desktop — Local-first desktop for AI coding agents
**624 stars/day** · [Repo](https://github.com/vastsa/PI-Desktop)

PI-Desktop is a cross-platform (macOS/Windows/Linux) Electron + Rust desktop app that lets you run AI coding agents fully locally: bring your own model, open any local project, install plugins — no account or relay required. The architecture separates a Rust host core from the pi Agent Harness, with user-installable plugins for extensibility. It's a privacy-first alternative to cloud-based agent IDEs, with 2.6K stars and active development as of today.

## 📡 Analysis

### Datasette 1.0a39 and 0.65.4 security releases
2026-09-11 · [Post](https://simonwillison.net/2026/Sep/11/datasette-security/) · tags: `security`, `datasette`, `llms`, `agentic-engineering`, `ai-security-research`

Simon Willison and Alex Garcia patched two Datasette versions after subtle security issues were reported, notably affecting instances mixing public and private tables. What's notable is the methodology: they ran a full security audit using Claude Fable 5.1, GPT-5.6, and GPT-6 Astra, then spent a week reviewing and fixing findings with a human-pair-review split (one writes the test, the other implements the fix). Willison says frontier-model security audits will now be standard in all Datasette development — a concrete example of AI-assisted security engineering becoming production practice.

### Native is now the future of mobile at Shopify
2026-09-10 · [Post](https://simonwillison.net/2026/Sep/10/shopify-react-native/) · tags: `coding-agents`, `llms`, `ios`, `android`, `shopify`

Shopify is abandoning React Native after six years in favor of separate Swift and Kotlin native codebases — and the reason is AI coding agents. The "build once, run everywhere" bet made sense in 2020 when cross-platform saved developer time; that calculus has shifted because agents can now handle enough of the dual-platform implementation, translation, testing, and review work to make the overhead acceptable again. Three major React Native libraries Shopify maintained (`react-native-skia`, `flash-list`, `restyle`) are being transitioned or archived, making this a meaningful event for the React Native ecosystem.
