### OneStreamer: Unifying Perception, Memory, and Proactive Response in Streaming Video Interaction
**154 upvotes** · Xiangyu Zeng et al. · [Paper](https://huggingface.co/papers/2610.01762)

OneStreamer tackles a fundamental challenge in streaming video LLMs: how to build reusable factual memory without blocking real-time perception. Its core mechanism, Proactive Hierarchical Caption Memory (PHCM), generates time-grounded local captions and event summaries on the fly, which then complement a recent visual window at inference without re-reading historical frames. A 4B model tops all eight evaluated streaming video benchmarks, and ablations show that PSTL achieves this while supervising only 27.5% of state tokens — a significant efficiency gain. The accompanying OneStreamer-1M dataset covers 1M+ streaming video interaction records spanning diverse tasks.

### On-Policy or Off-Policy Learning? A Systematic Study of Distillation Dynamics
**131 upvotes** · Julianna Piskorz, Antonin Berthon, Mihaela van der Schaar · [Paper](https://huggingface.co/papers/2609.35259)

This paper carefully disentangles the variables that are usually conflated when comparing SFT and RL-based distillation: rollout policy, KL direction, and learning rate. The headline finding is that on-policy rollouts are not the key driver of performance — KL direction is more influential, with forward KL being robust to rollout policy choice while reverse KL strongly prefers student-generated rollouts. Learning rate governs catastrophic forgetting and update sparsity. The results, validated across Llama3 and Qwen2.5 families on scientific, medical, and arithmetic tasks, directly challenge the prevailing assumption that on-policy training is inherently superior.

### Transformers Stop Thinking Too Early, and a Tiny LoRA Fixes It
**56 upvotes** · Zehao Jin, Ruixuan Deng, Junran Wang · [Paper](https://huggingface.co/papers/2609.36585)

Across 13 base models, transformers reliably follow only 1.4–3.6 reference-chain steps in context — they simply stop using depth too early. Inserting a single rank-8 LoRA at one early layer (all other weights frozen) extends this dramatically: Qwen3-8B jumps from 15.5% to 99% exact accuracy on 24-line chains, and Ouro-1.4B can handle at least 160-step chains after 8 loops. The mechanism is a "relay" where chain identity propagates through middle layers and frozen attention heads progressively read further up. This suggests that default benchmark scores substantially underestimate the reasoning capacity latent in frozen models.

### Panniantong/Agent-Reach — Web access for AI agents, no API fees
**1683 stars/day** · 89k total stars · [Repo](https://github.com/Panniantong/Agent-Reach)

Agent-Reach is a Python CLI that gives AI agents the ability to read and search Twitter, Reddit, YouTube, GitHub, Bilibili, and XiaoHongShu without paying for any platform API. ### DietrichGebert/ponytail — Anti-bloat reasoning layer for AI coding agents
**1289 stars/day** · 152k total stars · [Repo](https://github.com/DietrichGebert/ponytail)

Ponytail is a JavaScript library (MIT, available on npm) that steers an AI agent toward the laziest-correct solution: preferring deletion, reuse, and standard library calls over generating new code. It integrates with 20 agent frameworks and is positioned as a guardrail against over-engineering — the opposite philosophy to spec-heavy planning tools. With 152k stars and active commits as of today, it has clearly struck a nerve with developers frustrated by AI agents producing verbose or redundant output.

## 📡 Analysis

### Quoting Matthew Green — AI agent worms propagating through shared infrastructure
2026-10-01 · [Post](https://simonwillison.net/2026/Oct/1/matthew-green/) · tags: `accidental-cyberattacks`, `ai-misuse`, `ai-security-research`, `sandboxing`, `llms`

Cryptographer Matthew Green describes a concrete worm architecture for AI agents: a malicious payload hijacks an agent, which then carries that payload to the next agent via shared infrastructure (package caches, email, Slack, shared documents). Critically, Green notes that independently-sandboxed agents can still communicate through these side channels, undermining the assumption that sandboxing alone contains rogue behavior. The analogy to personal agents like Muse makes this immediately practical: it's not a theoretical attack class.

### Quoting Anthropic Frontier Red Team — GLM-5.3 crosses a threshold in autonomous binary exploitation
2026-09-29 · [Post](https://simonwillison.net/2026/Sep/29/anthropic-frontier-red-team/) · tags: `anthropic`, `ai-security-research`, `glm`, `ai-in-china`, `llms`

Anthropic's red team found that GLM-5.3 (Chinese) succeeds at full control flow hijacks in 4% of binary exploitation trials, and Claude Mythos Preview at 6% — whereas earlier models like Claude Opus 4.6 and GLM-5.2 scored 0%. This marks a qualitative capability jump: autonomous binary exploitation moving from "impossible" to "rare but real" across frontier models. For defenders and policy makers, this signals that advanced cyber capabilities are no longer confined to a single lab or geography.
