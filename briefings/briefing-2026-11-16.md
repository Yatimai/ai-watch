## 🔬 Research

### Envisioning Agentic Robotics: A New Era of Robotic Systems
**107 upvotes** · Grid Robotics, Qingfeng Lan et al. · [Paper](https://huggingface.co/papers/2611.18359)

The release of GPT-6 Astra acted as a catalyst, with frontier models using "agentic harnesses" now matching or beating task-specific policies on embodied benchmarks within weeks. The paper introduces the concept of **Embodied System 2** — a foundation model paired with a physical harness that reasons, invokes tools, and self-corrects in a closed loop. The authors argue the field still lacks shared definitions, evaluation frameworks, and roadmaps, and propose both a benchmark and a research path toward "sustained autonomy" with progressively broader responsibility. Worth reading as a potential reference framing document for the emerging agentic robotics subdiscipline.

### Gamer: A Generalist Vision-Language-Action Foundation Model for Long-Horizon Real-Time Game Agent
**86 upvotes** · Run Luo, Kuan Zhang et al. · [Paper](https://huggingface.co/papers/2611.18397)

Gamer is an end-to-end agent pre-trained on **tens of thousands of hours** of raw keyboard and mouse trajectories spanning games and simulated environments, then fine-tuned with sparse-thinking instruction tuning and a stable multi-turn RL method. It achieves skill-player-level performance on challenging 3D open-world games while also being competitive on 2D game benchmarks, all served via a cloud-edge inference engine that handles concurrent environments with low latency. The key insight: even mundane, repetitive interaction logs are a powerful data source when scaled — a signal that generalizes beyond gaming to any GUI-driven physical or digital agent. The shared pipeline for 2D/3D interfaces is directly relevant to real-world computer-use agents.

### VibePrevisBench: Evaluating Agentic Coding for 4D Scene Generation in Blender
**82 upvotes** · Yuzhe Chen, Muxi Diao et al. · [Paper](https://huggingface.co/papers/2611.15789)

VibePrevisBench is a **242-task benchmark** where coding agents must turn a brief (script, photo, continuation, or reference video) into an executable 4D Blender scene and render a graybox proxy video — bridging code generation and controlled video production. Evaluation is dual-track: rule-based scene checks against hidden ground truth facts, plus a VLM judge verifying visual fidelity. Testing 11 frontier coding agents revealed a consistent failure pattern: agents handle basic camera work fine but break on complex spatial reasoning, and critically, they fail to self-correct even when inspecting their own renders. A concrete gap to target for teams building code-generation agents in 3D/creative pipelines.

## 🛠 Tools

### dream-num/univer — Open-source AI Office SDK
**1,878 stars/day** · [Repo](https://github.com/dream-num/univer)

Univer (27,610 total stars) is a TypeScript SDK that embeds Sheets and Docs editing, collaborative computation, and file processing directly into any product — for both human users and AI agents. It's designed as an extensible open-source core that can be connected to custom applications or agents, making it a credible open alternative to embedding Google Sheets or Office365. The spike in stars suggests a recent viral moment; worth watching for teams building AI-driven data or document workflows.

### NVIDIA/SkillEvaluator — Multi-tier AI agent skill evaluation framework
**953 stars/day** · [Repo](https://github.com/NVIDIA/SkillEvaluator)

SkillEvaluator (2,419 stars, Apache 2.0, Python 3.12–3.14) is a CLI + CI-integrated tool that validates [Agent Skills](https://agentskills.io/) spec folders through quality gates, semantic overlap detection, synthetic dataset generation, and live before/after behavioral comparisons. Installable via `pip install skillevaluator` with no API key required for tier-1 validation. It's part of NVIDIA's broader Verified Skills pipeline and backed by an arXiv paper, making it one of the more rigorous open-source options for standardized agent skill testing.

### alibaba/open-code-review — Production-grade LLM code review at Alibaba scale
**946 stars/day** · [Repo](https://github.com/alibaba/open-code-review)

OpenCodeReview (52,784 total stars, written in Go) uses a hybrid architecture — deterministic rule pipelines for NPE, thread-safety, XSS, and SQL injection, combined with an LLM agent for contextual review — delivering precise line-level comments compatible with both OpenAI and Anthropic APIs. It has been battle-tested at Alibaba's internal scale before open-sourcing, which gives it a credibility edge over greenfield LLM-only review tools. Teams looking for a self-hostable, security-focused alternative to GitHub Copilot code review have a strong candidate here.
